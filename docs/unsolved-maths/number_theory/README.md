# Number Theory section

Cascade-applications of the 14 A-N primitive class operators to open problems in
**number theory**, per the Wikipedia
[List of unsolved problems in mathematics](https://en.wikipedia.org/wiki/List_of_unsolved_problems_in_mathematics#Number_theory).

Number theory is positioned **after** the Hilbert + Millennium Prize sections of
PR #677 — the natural ordering by (i) historical priority (Hilbert problems +
Millennium Prize problems already addressed); (ii) some major number-theory
problems are subsumed under Hilbert 8 (Riemann + Goldbach + twin primes) and
Millennium 4 (BSD elliptic curves). What remains in this section is the
**non-Hilbert / non-Millennium** number-theory canon.
