## 1. Problem statement

Find an explicit construction of all abelian extensions of a given algebraic number field K using values of analytic / transcendental functions, in analogy with:
- **Kronecker-Weber theorem**: every abelian extension of ℚ is contained in some cyclotomic field ℚ(ζ_n) — generated by values of e^(2πi/n).
- **Complex multiplication**: abelian extensions of imaginary quadratic fields are generated by values of elliptic modular j-function and elliptic functions at CM points.

**Hilbert's question**: Construct abelian extensions of arbitrary number fields by analogous explicit / analytic means.

## 2. Why it is open

- **ℚ** (rationals): solved by Kronecker-Weber 1853/1886.
- **Imaginary quadratic fields**: solved by theory of complex multiplication (Kronecker, Weber, Hecke, Shimura, Deuring) — uses singular moduli of elliptic curves.
- **Totally real fields** and **CM fields**: partial — Shimura, Hilbert modular forms; Stark conjectures.
- **General number fields**: open. No known explicit / canonical construction of generators.

The difficulty: while class field theory (Artin, Takagi, Chevalley) PROVES existence and gives Galois-theoretic structure, it doesn't give EXPLICIT generators by analytic / special-value formulae.

## 3. Framework reading

**Substrate-level reframing**: this is a **Class I + Class N + Class L** cascade-shape question.

The Galois group Gal(K^ab/K) of the maximal abelian extension is abstractly known via class field theory; the open part is **explicit construction via cascade composition**.

Two cascade readings:

(a) **Class I cyclic + Class N rational** — abelian extensions are characterized by their Galois groups (cyclic / direct sum of cyclic). The generators must be cyclic-group-respecting analytic values. The cascade asks: for a given number field K, which Class I cyclic structure governs Gal(K^ab/K), and what Class N rational / analytic special values realize it?

(b) **Class L spectral on adelic Laplacian** — Langlands program reformulates class field theory spectrally (automorphic forms on GL_n(A_K)). Class L cascade on the appropriate operator gives spectral signatures whose eigenvalues encode generators.

(c) **Class K asymptotic-DOF + Stark conjecture** — Stark units conjecturally generate abelian extensions of arbitrary number fields. They're defined as asymptotic values (s → 0) of L-functions — a Class K pin-slot at the L-function's special value.
