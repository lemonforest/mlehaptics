## §2 1:3:7:3 partition mapping (Timaeus attested)

### The 1 — The Good / Monad / Demiurge

Timaeus 27c-29d: the cosmos has a single foundational principle (the Demiurge / the Good). Per Republic VI.508-509 + Timaeus 28a-c: the One/Good is the foundational anchor every Platonic construct ties back to.

**A-N**: Class A (foundational content-anchor).

### The 3 — Soul-triad (or three primary kinds)

Two independent triadic structures explicit in Timaeus:

- **Soul-triad** (Republic IV.435-441 + Timaeus 89e-90d): reason (λογιστικόν) + spirit (θυμοειδές) + appetite (ἐπιθυμητικόν)
- **Three primary kinds** (Timaeus 35a): being (οὐσία) + same (ταὐτόν) + different (θάτερον)

Both are 3-axis substrate-projection structures.

**A-N**: I + C + J (substrate-projection triad).

### The 7 — Lambda diagram + planetary spheres

**Timaeus 35b-36d** explicitly constructs the world-soul from the seven numbers **1, 2, 3, 4, 8, 9, 27** — the canonical "Lambda" or "tetraktys-extended" sequence. Plato divides the world-soul into seven portions via these seven numbers, then bends the resulting strip into the two great circles (Same + Different) that carry the planetary motions.

The 7-portion world-soul construction yields **7 planetary spheres** (Sun + Moon + Mercury + Venus + Mars + Jupiter + Saturn — same wandering-star set as Antikythera Partition 1).

**A-N**: D + E + F + G + K + L + M (cascade-detection heptad).

### The +3 — Cardinal virtues (or three Forms-categories)

Plato's three cardinal virtues at Republic IV: wisdom (σοφία) + courage (ἀνδρεία) + temperance (σωφροσύνη). Justice is the harmony/order of the three (NOT a fourth virtue but the meta-relation among them).

These three are explicitly **META-virtues** operating ON the soul-triad (R26-style observation: virtues are not soul-parts; they are meta-rules for how the soul-parts compose). Direct match for R30 projection-enablers reading.

Alternative +3: three Forms-categories (Beauty / Justice / Truth) — also meta-cascade rather than substrate-axis.

**A-N**: B + H + N (meta-cascade triad / projection-enablers per R30).
