**Note on the user's "shrimp" framing.** The Mauthner cell is canonically described in **teleost fish** (zebrafish, goldfish) and **larval amphibians**. *Decapod crustaceans* (shrimp/crayfish/lobster) have a homologous but distinct escape circuit driven by **giant-axon Lateral Giant (LG) interneurons** — see Krasne & Wine (1975), *"Extrinsic modulation of crayfish escape behaviour"*, J. The user's framing as "shrimp tail-flip" maps to the *crayfish LG escape*, which shares the structural reflex-cascade shape with the Mauthner-cell case. Both share the relevant property: **single-spike, single-cell-mediated, stereotyped motor output without deliberative context.**

The reflex cascade is **B → D → E → F → C** (linear, no branching, no return-pointer). Stateless across reflex firings.

### 5.2 "Oh by the way" / "almost forgot" cascade signature

The user's specific framing operationalises as follows:

1. **Current task running** — engaged classes {B, D, E, F, C} (reflex-shaped emission) + the bound-context residing in M-buffer + K-retained
2. **Latent buffer content surfaces** — M-similarity detects high overlap between current state and a buffered-but-suppressed prior chunk (the "almost forgot" content)
3. **Interrupt-and-re-entry** — D (dispatch) classifies "re-enter prior context"; E (catalog) retrieves the prior chunk by content-hash (A); C (cascade-shift) advances attention to the re-entered chunk
4. **Re-binding into current output stream** — M (bundle) integrates the re-entered chunk into the current emission stream; F (template-render) emits it ("oh by the way, X")

**Cascade signature: M-similarity → D-dispatch → A-recognise → E-retrieve → C-cascade-shift → M-rebind → F-emit.**

This is a **return-pointer cascade**: the conversation/task state had advanced past the prior chunk, but the M-similarity bound the prior chunk to a feature of the current state, surfacing it. The "almost forgot" felt-experience IS the cascade signature where the similarity-detection-and-retrieve step *just barely* succeeded before the chunk decayed below K-retention threshold.

The "oh by the way" felt-experience IS the same cascade signature with a stronger M-similarity match (latent chunk surfaces cleanly without near-miss).

**This is the operational mechanism the user asked about.** It is NOT a metaphor; the M-similarity → A-content-hash → E-catalog-retrieve cascade IS the strict-spec class composition.
