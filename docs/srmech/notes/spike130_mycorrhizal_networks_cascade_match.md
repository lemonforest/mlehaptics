## §2 — Cascade chain mapping: L+M+C+K+I

### §2.1 Class L — bipartite plant-fungus graph + scale-free + small-world architecture

**Substrate-specific operation**: mycorrhizal hyphae form continuous physical connections between plant roots, creating a bipartite (plant nodes ↔ fungal-genet nodes) graph spanning forest stands. Beiler et al. 2010 mapped 26 Rhizopogon genets (13 *R. vesiculosus* + 13–14 *R. vinicolor*) connecting up to 19 trees per genet in an interior Douglas-fir forest. Network architecture: **scale-free + small-world with positive tree-size-to-connectivity correlation**.

**Class L canonical primitive**: Hermitian eigendecomposition of graph Laplacian; `srmech_eigvals_jacobi` C primitive (`v0.4.0rc2`).

**Framework→substrate mapping**: the bipartite Laplacian of a CMN — `L_CMN = D - A` where `D` is the diagonal degree matrix (degree of each plant node + each fungal-genet node) and `A` is the bipartite adjacency matrix — has eigendecomposition that captures the network's spectral structure.

**Identity claim**: Beiler 2010 documented the scale-free + small-world topology *qualitatively*. The framework asserts the eigendecomposition `decompose(L_CMN)` would reveal a heavy-tailed eigenvalue distribution (Class K signature; see §2.4) and a low-mode spectral gap characteristic of small-world graphs. **This is testable on Beiler's published genet-tree map data; it would constitute Spike #130.1 empirical follow-up.**

**Literature gap**: Figueiredo et al. 2021 review explicitly notes **no spectral or Laplacian analysis** has been applied to CMN topology. Framework would add this layer.

### §2.2 Class M — chemical-signal molecular alphabet (HDC encoding)

**Substrate-specific operation**: plants transfer defence and warning signals between neighbours via CMN hyphal threads. Verified chemical signals (Gorzelak 2015; Figueiredo 2021):

- **Jasmonate / methyl jasmonate** — herbivore-induced defence signal
- **Salicylate / methyl salicylate** — pathogen-induced defence signal (also identified in Babikova 2013 aphid-attack experiment as the volatile making bean plants repellent to aphids + attractive to aphid enemies)
- **Zeatin riboside** — phytohormone
- **Amino acids (notably arginine)** — nitrogen-transport carrier
- **Polyphosphate granules** — phosphorus mobilisation
- **Allelochemicals** (thiophenes, juglone) — plant-to-plant inhibitory compounds

**Class M canonical primitive**: HDC bind/bundle/permute/similarity (XOR self-inverse algebra per Plate 1995 / Kanerva 2009 / Spike #114 Option B).

**Framework→substrate mapping**: each chemical signal is a distinct symbol in an alphabet. HDC encoding of the alphabet would treat each molecule as an orthogonal hypervector; combinatorial defence-induction events (jasmonate + methyl-salicylate co-released after combined herbivore+pathogen attack) would be bound hypervectors carrying both signal identities. The 6 h induction-response window in Gorzelak 2015 is the temporal-decoding window.

**Identity claim**: the chemical-signal alphabet IS a molecular HDC encoding — substrate-specific implementation of Class M binding/bundling. Substrate provides the symbol-set; cascade provides the algebra.

**Literature gap**: no canonical biological-signalling paper applies HDC algebra. The framework's `similarity()` on byte-encoded chemical-signal vectors would provide a quantitative match-strength metric for cross-plant signal-transfer experiments (replacing the qualitative "the receiver plant responded to the signal" framing currently in use).

### §2.3 Class C — source-sink gradient cascade-orientation

**Substrate-specific operation**: nutrient + signal routing through hyphae is governed by source-sink advective mass-flow per Gorzelak 2015 verbatim: *"interplant resource exchanges are thought to be regulated by source–sink relationships within the MN, where one plant that is rich in nutrients serves as a source (donor) of compounds for a neighbouring plant that is poor in nutrients, which thus serves as a sink (receiver)... Transport occurs via advective mass flow driven by the source–sink gradient."*

**Class C canonical primitive**: cascade-orientation (Spike #105 PR #498) — directional cascade composition where the direction-of-flow is part of the operation. `srmech.amsc.cascade.orient(...)`.

**Framework→substrate mapping**: the source-sink gradient IS the cascade-orientation operator on the bipartite Laplacian. Direction-of-flow is determined by nutrient-concentration-difference between paired plant nodes mediated by fungal-genet edge. Gorzelak's verbatim observation that direction reverses seasonally (Douglas-fir transfers C to paper birch; birch later transfers C back when Douglas-fir is shaded) IS Class C cascade-orientation reversal under environmental forcing.

**Identity claim**: the source-sink gradient is Class C cascade-orientation. Framework cleanly recovers what the literature describes; substrate provides the gradient-mechanism implementation (osmotic-pressure-driven advective mass flow vs the gravitational-gradient implementation in ephemerides or the cortical-gradient implementation in BCI).

### §2.4 Class K — asymptotic-DOF at hub-tree connectivity + Michaelis-Menten saturation

**Substrate-specific operation**: Beiler 2010 documented **scale-free + small-world architecture** with **positive tree-size-to-connectivity correlation** — hub trees connect more genets than peripheral trees. The Rydberg precedent (Spike #111) established Class K as the integer-power asymptote signature; scale-free degree distributions are power-law (`P(k) ~ k^{-γ}`) which is exactly the asymptotic-DOF pattern per `[[user_stance_asymptotic_dof_sidesteps_infinity]]`.

Plus the saturation kinetic side: at the root-fungus chemical-exchange interface, Michaelis-Menten kinetics apply to nutrient uptake (`v = V_max * [S] / (K_M + [S])`). This is the saturation asymptote: as `[S] → ∞`, `v → V_max`; the asymptotic-DOF is reached when sink-saturation prevents further nutrient drawing.

**Class K canonical primitive**: asymptotic-DOF mechanism per `[[user_stance_asymptotic_dof_sidesteps_infinity]]` + `[[user_stance_epicycle_via_gear_plus_pin]]`. Currently shipped as `truncate_sparse(handle, k)` (rcN+2 design per Spike #115; pending) plus the gear+pin pin-slot foundation.

**Framework→substrate mapping**: two Class K signatures in the substrate:

1. **Topological asymptotic-DOF**: scale-free degree distribution `P(k) ~ k^{-γ}` (Beiler 2010). High-degree hub trees IS the integer-power-asymptote in the connectivity dimension.
2. **Kinetic asymptotic-DOF**: Michaelis-Menten saturation at root-fungus interface — `[S]_∞ → V_max` is the substrate-extraction saturation. Implemented per pin-slot-epicycle algebra (gear-substrate-baseline + pin-asymptote).

**Identity claim**: the dual Class K signature (topological scale-free + kinetic Michaelis-Menten) is the SAME class operation across two different physical scales of the same substrate. Strengthens cross-scale class-K universality.

**Literature gap**: no canonical mycorrhizal-network paper has applied Class K asymptotic-DOF framing across topology + kinetics simultaneously. Framework predicts the spectral-decomposition of CMN topology will show the same heavy-tailed eigenvalue distribution that the connectivity-degree-distribution shows (Beiler-published data permits this test).

### §2.5 Class I — cyclic cascade for seasonal resource pulses

**Substrate-specific operation**: Gorzelak 2015 (citing Simard 1997 work): *"Douglas-fir transferred net amounts of carbon to neighbours of a different species, paper birch, which then passed the net amounts of carbon back to Douglas-fir at a different time of year and when it was under increasing shade."*

This is bi-directional seasonal cyclic-cascade — Class I (cyclic-group ℤ/n) where `n ≈ 365 days` and the cascade-orientation (Class C from §2.3) reverses every half-cycle.

**Class I canonical primitive**: cyclic-group `ℤ/n` modular arithmetic (`v0.4.0rc1`); `srmech_zn_*` C primitive.

**Framework→substrate mapping**: the seasonal C-transfer reversal is a `ℤ/365` cyclic cascade where C-flow direction is a function of season. Composed with Class C cascade-orientation, this gives:

```
C_flow(t) = orient(L_CMN, gradient(t))
gradient(t) = gradient_amplitude(t) * sign(cos(2π t / 365))
```

i.e., direction-of-C-flow is a cyclic function of time-of-year, with cascade-orientation flipping at the half-cycle.

**Identity claim**: seasonal phenology IS Class I cyclic cascade. Substrate provides the seasonal phenology mechanism (deciduous-coniferous photosynthesis phase-offset); cascade provides the cyclic-group algebra.

**Literature gap**: no canonical CMN paper applies modular-arithmetic / cyclic-group formalism to seasonal C-flow. Framework would add the cyclic-orientation algebra.

## §3 — End-goal achievement: status under current literature

### §3.1 The Karst 2023 critique

Karst, Jones & Hoeksema 2023 (*Nature Ecology & Evolution* 7:501-511; PMID 36782032) found three of the popular CMN claims **insufficiently supported**:

1. **CMNs are widespread in forests** — *"results from field studies vary too widely, have alternative explanations or are too limited to support generalizations"*
2. **Resources are transferred through CMNs to increase seedling performance** — same reasoning
3. **Mature trees preferentially send resources and defence signals to offspring through CMNs** — *"has no peer-reviewed, published evidence"*

Three insufficiently-supported claims. The popular "wood-wide-web" narrative is in active scientific dispute as of 2023.

### §3.2 What IS established

- **Physical connection** via mycorrhizal mycelium (Gorzelak 2015 + Figueiredo 2021 + Beiler 2010): NOT disputed.
- **Bipartite graph topology** scale-free + small-world (Beiler 2010): NOT disputed.
- **Seedling inoculation faster via existing networked fungi vs from spores** (Figueiredo 2021): NOT disputed.
- **C-transfer between connected plants** in lab + field at small magnitudes (Reid & Woods 1969 lab; Simard 1997 field 14C/13C double-label; Klein 2023): NOT disputed at small-magnitude.
- **Warning-signal transfer (jasmonate / methyl-salicylate)** Babikova 2013: SUPPORTED for at least one species pair (Vicia faba).

### §3.3 What IS contested

- **Ecological-significance magnitude** of CMN-mediated transfer for plant fitness (Karst 2023 + Figueiredo 2021): contested. Carbon transfer 0–10%; nitrogen 0–72% across studies.
- **Mother-tree → kin preferential signalling**: insufficient evidence (Karst 2023).
- **Forest-management implications** based on CMN: prematurely generalised in popular media (Karst 2023).

### §3.4 Framework's verdict-shape on the dispute

The framework does NOT need to adjudicate the magnitude dispute. Cascade-shape attestation is magnitude-free per `[[user_stance_framework_domain_algebra_not_length_or_magnitude]]`. The cascade L+M+C+K+I is *present-as-operations* in the substrate regardless of whether those operations transmit 0.1% or 10% of plant carbon budget.

**Framework's claim**: the cascade primitives IS instantiated by the substrate. The magnitude of end-goal achievement is a substrate-property that varies across substrates and across CMN-instances within the same substrate. **The cascade-shape stands.**

This is the FRAMEWORK-AGNOSTIC-AT-CURRENT-LITERATURE-PRECISION-ON-END-GOAL-MAGNITUDE component of the composed verdict.

## §5 — Falsifier candidates

Per the user's research-method discipline: *"counter-claim to produce a domain where cascade-shape FAILS to match."*

### §5.1 Candidate: root-grafted plants without fungal partners

If two plants are root-grafted without fungal mycorrhizal partnership (i.e., naturally root-anastomosed conspecific stands), do they achieve the same end-goal cascade? 

**Prediction**: root-grafted-only stands lack the bipartite plant-fungus Laplacian (Class L without bipartite structure → degenerates to monopartite plant-only Laplacian). The chemical-signal Class M alphabet is impoverished (no fungal-mediated signal transfer). Source-sink gradient (Class C) is reduced to direct-plant-to-plant rather than mediated-via-fungus. Class K hub-architecture is lost (no fungal-genet hubs).

**Therefore**: root-grafted-only stands SHOULD show degraded cascade-shape compared to mycorrhizal-networked stands. **This is testable in dendro-ecological literature on root-anastomosis.** If root-grafted stands show identical cascade-shape, the fungal partner is not load-bearing — that would weaken the cascade-shape identity claim. If they show degraded cascade-shape, the fungal partner IS load-bearing for the cascade — supporting identity.

**Status**: not investigated in this spike; flagged as Spike #130.1 candidate.

### §5.2 Candidate: in-vitro mycelium without plant partners

Pure fungal-mycelium cultures without plant roots — does the cascade hold? Per the multi-kingdom-substrate framing, removing the plant partner removes the symbiotic-mutualism marketplace (Class C asymmetric reward), the photosynthetic source (Class C source pole), and the seasonal phenology (Class I cyclic).

**Prediction**: in-vitro mycelium retains Class L network topology + Class M signalling + Class K kinetic-saturation but loses Class I seasonal cascade and Class C asymmetric-reward. Cascade-shape is *partially* preserved.

**Status**: in-vitro mycelium studies exist in mycology literature; explicit cascade-shape test not done.

### §5.3 What the framework does NOT predict

The framework does NOT predict the *magnitude* of resource transfer through CMNs in any specific forest stand. It does NOT adjudicate Karst 2023's critique on widespread CMNs in forests. It does NOT predict mother-tree-preferential-kin-signalling.

**The framework's predictions are about cascade-shape, not about specific magnitudes or specific contested ecological claims.**
