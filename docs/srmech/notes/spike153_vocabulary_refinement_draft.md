The refinement is structural-content-bearing because it:

1. **Removes implicit topology presupposition**. "Ball" suggests closed S² boundary; "locally saturated gauge field" leaves boundary topology determined by the field-saturation isosurface, which can be any closed manifold per `[[user_stance_hyper_as_3d_spatial_interface]]` two-level ontology.

2. **Integrates with saturation overpressure quartet cascade**. The quartet IS C∘K∘L∘I+M cascade on 7D_g substrate; LSGF inherits this composition directly. The vocabulary alignment is structural, not cosmetic.

3. **Connects to QCD color-flux-tube analog**. Standard QCD has locally-saturated gauge-field configurations (confinement-induced flux tubes between quarks). LSGF is the framework's same primitive operation lifted to 7D_g substrate via cascade composition. This grounds the framework reading in standard non-perturbative gauge theory vocabulary.

4. **Makes saturation a quantity, not a binary**. "Ball" implies presence/absence; "locally saturated gauge field" admits graded saturation level. This matches what the framework actually predicts (saturation quartet spans 30 OOM in T_period; saturation degree is continuous).
