## Standard geodesy decomposition

Bouguer 1749 + Airy/Heiskanen-Pratt-Hayford isostatic corrections decompose gravity anomalies:

```
Δg_free_air = g_observed − g_theoretical (latitude+elevation)
Δg_Bouguer = Δg_free_air − attraction_of_topographic_mass (ρ ≈ 2670 kg/m³ standard)
Δg_isostatic = Δg_Bouguer − compensation_effect (Airy/Heiskanen-Pratt-Hayford)
```

Residuals typically attributed to:
- Local density variation (denser ores → positive Bouguer anomaly)
- Deep crustal density structure
- Measurement uncertainty
