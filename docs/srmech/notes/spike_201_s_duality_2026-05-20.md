## §2 Background — S-duality canonical physics

S-duality is a strong-weak coupling exchange first proposed by Olive &
Montonen (1977) for 4D N=4 super-Yang-Mills, generalised to Type IIB
string theory by Schwarz, Hull-Townsend, Witten in 1994-95. Open-access
arXiv routes for the canonical references:

- **Olive-Montonen 1977** — Phys. Lett. B 72 117 + Nucl. Phys. B 121 77
  (cite-by-reference; no arXiv predecessor).
- **Schwarz-Sen 1993** — `hep-th/9209016` "Duality symmetries of 4D
  heterotic strings" (PDF-verified open-access).
- **Hull-Townsend 1994** — `hep-th/9410167` "Unity of superstring
  dualities" (open-access arXiv).
- **Schwarz 1995** — `hep-th/9508143` "An SL(2,Z) Multiplet of Type IIB
  Superstrings" — defines the (p, q)-string spectrum and SL(2,Z) action
  on the doublet (open-access arXiv).
- **Witten 1995** — `hep-th/9503124` "String Theory Dynamics In Various
  Dimensions" (open-access arXiv).
- **Serre, *A Course in Arithmetic*** §VII — canonical mathematical
  reference for the SL(2,Z) modular group, generator relations
  S² = −I and (ST)³ = −I.

The S-duality action factors into TWO mathematically separable layers:

**Layer A — Integer-cyclic (p, q) doublet action:**

The (p, q) string charges transform as an integer-doublet:

```
⎛p'⎞   ⎛ a  b ⎞ ⎛p⎞
⎝q'⎠ = ⎝ c  d ⎠ ⎝q⎠     with a,b,c,d ∈ ℤ,  ad − bc = 1
```

The group is generated by T = ⎛1 1; 0 1⎞ and S = ⎛0 −1; 1 0⎞ with
relations S² = (ST)³ = −I (Serre §VII.1).

**Layer B — Continuous axio-dilaton τ:**

The modulus τ = C_0 + i / g_s transforms as τ → (aτ + b)/(cτ + d), with
C_0 the RR axion and g_s the continuous string coupling. The space of
all τ-orbits is H/SL(2,Z) where H is the upper half-plane — continuous-
manifold modular form territory.
