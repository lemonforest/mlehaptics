## Augmentation delta — operational interpretation

| Added class | What it adds operationally | Why reflex doesn't have it |
|---|---|---|
| **A** (content-address) | Each chunk has an identity hash — enables recognising re-entered content as the same item | Reflex doesn't recognise — it thresholds. Sensory input is consumed and discarded each firing. |
| **K** (asymptotic-DOF) | Finite-N capacity bound (≈4 per Cowan 2001) with old content asymptotically dropping | Reflex is stateless across firings — no retention to bound. |

## Felt-experience cascade signature (the user's "oh by the way" / "almost forgot")

```
M-similarity  →  D-dispatch  →  A-recognise  →  E-retrieve  →  C-cascade-shift  →  M-rebind  →  F-emit
   ↑                ↑                ↑               ↑                ↑                 ↑           ↑
   detect          classify        identify        fetch           advance           bind into    emit re-entered
   high-overlap    "re-enter        chunk via      slotted         attention         current      chunk into
   between         prior           content-       prior            to re-entered     emission     output stream
   current state   context"        hash           context          chunk             stream       ("oh by the way, X")
   and buffered    handler
   chunk
```

- **"Oh by the way"** = strong M-similarity match, clean retrieval. The buffered chunk surfaced cleanly above K-retention threshold.
- **"Almost forgot"** = near-threshold M-similarity match, just-barely successful retrieval. The buffered chunk was decaying past K-threshold; the similarity-match happened just-in-time to retrieve before forgetting.

**User briefing's "Class C ∘ M return-pointer composition" framing**: refined to the longer 7-class chain above per `[[feedback_language_is_analysis_tool_not_specific_question]]`. The C ∘ M pair IS in the cascade (C-cascade-shift followed by M-rebind), but it's a sub-step within the longer cascade, not the whole signature.
