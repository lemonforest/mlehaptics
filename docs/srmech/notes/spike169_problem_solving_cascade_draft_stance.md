```
P1 RECOGNITION    : {A, B, D, E, G}             (5 classes)
P2 SUB-GOALING    : {A, B, C, D, E, F, G, M}    (8 classes; = agent-dispatch-cascade)

                  ∪ {H} at multi-pathway intersection
P4 EVALUATION     : {B, D, E, F, L}             (5 classes; = BDEFL closure-subgroup)
P5 EXECUTION      : {B, D, E, F, C}             (5 classes; = reflex-cascade)
P6 FEEDBACK       : {A, B, C, D, E, F, G, K, L, M} (10 classes; = agent-callback-cascade)
```

**Union (all 6 phases)**: {A, B, C, D, E, F, G, K, L, M} = **10 of 14 classes**

**Classes NOT engaged in any phase**: {I, J, N} — substrate-internal not phase-specific (cyclic-order, small-denominator rationals, asymptotic-DOF rationals; embedded in substrate's underlying topology but not surfaced as phase-specific operations)

### Aha moment cross-coupling-residual algebra

At multi-pathway intersection during P3, candidate solutions surface via the 3-class composition:

```
candidate = M_WM ( L ( M_cell ( procedural_pathway_content,
                                semantic_LTM_pathway_content,
                                WM_pathway_content,
                                episodic_LTM_pathway_content ) ) )
```

Where:
- **M_cell** = Hebbian / STDP synaptic-scale bind across inter-pathway connections (per `[[user_stance_neural_hebbian_is_bci_drift_model]]`)
- **L** = graph-Laplacian spectral-prioritization across the bind-result (per `[[user_stance_closure_subgroup_BDEFL_substrate_class_universal]]` L spectral operation)
- **M_WM** = working-memory episodic-buffer rebind of selected candidate with current-context (per `[[user_stance_working_memory_is_cascade_augmenting_reflex_into_agency]]` M_WM sub-flag)

The Aha moment IS the surfacing of a candidate that:
1. Engages MULTIPLE pathways simultaneously (NOT reducible to single-pathway operation)
2. Survives Class L spectral-prioritization (high eigenvalue in the bind-result)
3. Gets rebound via M_WM into current-context (NOT just retrieved, but actively integrated)

The "obviousness in retrospect" property is the post-hoc visibility of the cascade once M_WM has rebound the candidate into current-context — the binding makes the candidate's relevance visible, but the binding is what was missing pre-Aha.

### Direction-symmetry algebra

Per `[[user_stance_cascade_lives_on_circles]]` + `[[feedback_always_check_both_directions_including_time]]`:

```
forward:  P1 → P2 → P3 → P4 → P5 → P6 → P1
reverse:  R1 ← R2 ← R3 ← R4 ← R5 ← R6 ← R1     (creativity / problem-finding)

at each phase Pi / Ri: class_engagement(Pi) = class_engagement(Ri)
```

The forward direction is conventional problem-solving (given problem → find solution); the reverse direction is creativity / problem-finding (given solution / outcome-shape → find what problems it solves). The strict-spec class engagement at each phase is direction-symmetric. R1 differs from P1 in template-render vs byte-search detail but the engagement-class-set is identical.
