## The algebraic content of H4

The cascade-direct 4D Laplacian per bonus 8 is positive-semidefinite:

```
L_Euclidean_4D = L_spatial_1 + L_spatial_2 + L_spatial_3 + L_temporal
            (all four terms positive; sum is PSD)
```

The Lorentzian d'Alembertian per bonus 8's Class O:

```
L_Lorentzian = +L_spatial_1 + L_spatial_2 + L_spatial_3 − L_temporal
            ≡ L_spatial_direct_product − L_temporal_factor
```

The H4 reframing: these are **the same equation written on different sides of the equal sign**. If we write the eigenvalue equation as

```
L_spatial_1 + L_spatial_2 + L_spatial_3 = E + L_temporal
```

then `+L_temporal` on the RHS is equivalent to `−L_temporal` on the LHS. The Lorentzian d'Alembertian is the *same* equation as the Euclidean Laplacian, with the temporal term moved to the other side of the equal sign. There is no operational difference; only positional.

If this reading holds, **Class O is not a primitive operation** — it is the shadow of equation-side choice. Wick rotation is not "doing something to the temporal factor"; it is "writing the equation with the temporal factor on the other side."
