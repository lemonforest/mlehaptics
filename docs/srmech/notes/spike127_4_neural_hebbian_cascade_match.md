## §1 — Substrate operations vs canon (Bucket 1)

### §1.1 Operations the neural-Hebbian substrate exhibits

From PDF-extracted PMC + arXiv literature:

1. **Hebbian coincidence-detection** (Hebb 1949 cite-by-ref; Markram-Gerstner-Sjöström 2012 PMC3395004 PDF-extracted overview): *"cells that fire together, wire together"*. Coincidence of pre- and post-synaptic activity strengthens the connection between them; biological realiser is NMDA-receptor Mg²⁺-block requiring simultaneous pre-synaptic glutamate-release AND post-synaptic depolarisation to admit Ca²⁺ influx.

2. **Spike-timing-dependent plasticity (STDP)** (Gütig-Aharonov-Rotter-Sompolinsky 2003 PMC6742165 PDF-extracted): explicit temporal-asymmetric Hebbian rule. Weight update `Δw = -λf_(w)·K(Δt)` for Δt ≤ 0 (post-before-pre → LTD) or `Δw = +λf_+(w)·K(Δt)` for Δt > 0 (pre-before-post → LTP), with temporal kernel `K(Δt) = exp(-‖Δt‖/τ)`, τ ≈ 20 ms following Bi-Poo 1998 measurements. Sgritta et al. 2017 PMC6596728 measured ±25 ms window at cerebellar mossy-fibre / granule-cell synapse.

3. **Cross-correlation-driven weight dynamics** (Gütig et al. 2003): drift equation `ẇ = -λf_(w)∫_{-∞}^{0} dΔt K(Δt) Γ_pre,post(Δt) + λf_+(w)∫_{0}^{∞} dΔt K(Δt) Γ_pre,post(Δt)` where `Γ_pre,post(Δt) = ⟨ρ_pre(t) ρ_post(t+Δt)⟩_t` is the pre-post spike-train cross-correlation function. STDP kernel temporally filters the cross-correlation; weight dynamics are driven by *cross-correlation matrix* of input/output spike trains.

4. **Oja's rule → first-principal-eigenvector convergence** (Oja 1982 cite-by-ref; scholarpedia + Wikipedia + olshausen handout PDF-extracted concept): `Δw = ηy(x − yw)` with `y = w^T x`. *Theorem*: weight vector w converges asymptotically to first principal eigenvector q_1 of input covariance matrix C = ⟨xx^T⟩, with `lim_{n→∞} σ²(n) = λ_1` (principal eigenvalue). This is a *Class L primitive operation* expressed in biological substrate.

5. **Bienenstock-Cooper-Munro (BCM) sliding threshold** (Bienenstock-Cooper-Munro 1982 cite-by-ref via *J Neurosci* prohibited; Wikipedia extraction): `ṁ_j(t) = φ(c(t), c̄(t)) d_j(t)` with `φ(c, c̄) = c(c − θ_M)` and sliding threshold `θ_M = c̄²`. Negative below threshold (LTD), positive above (LTP). Provides selectivity / orthogonality to non-principal input patterns. Two-eigenvalue separation: BCM converges to *selective* weight vector orthogonal to suppressed input subspace.

6. **Homeostatic synaptic scaling** (Turrigiano 1998 cite-by-ref *Nature* prohibited; Turrigiano 2012 PMC3249629 PDF-extracted overview): multiplicative scaling of all excitatory synapses preserving relative strength. Phenomenological form `dω/dt = γ H(ν_target - ν_actual)·ω` (per search synthesis; Turrigiano 2012 does not give explicit ODE in this article). Operates on hours-to-days timescale; balances Hebbian growth that would otherwise saturate.

7. **Competitive resource trafficking** (Triesch-Vo-Hafner 2018 PMC6181566 PDF-extracted): explicit ODE system for receptor binding in synaptic competition: `ẇ_i = -βw_i + αp(s_i - w_i)`, `ṗ = -δp + γ + Σ_i βw_i - Σ_i αp(s_i - w_i)`. *Multiplicative steady state*: `w_i^∞ = F · s_i` with filling fraction `F = 1/(1 + βδ/(αγ))` identical across all synapses. *Saturation*: `F_max = min{1, R/S}` — Class K asymptotic-DOF capacity limit.

8. **Three-factor learning rules** (Frémaux-Gerstner 2016 PMC4717313 PDF-extracted): `ẇ = M × H(pre, post)` where M is neuromodulator (dopamine / acetylcholine / norepinephrine / serotonin) gating Hebbian coincidence H. Reward-modulated STDP. Multiplicative gating preserves Hebbian temporal structure but conditionally enables/disables update.

9. **Dynamic cross-correlation cascade** (olde Scheper et al. 2018 PMC5768644 PDF-extracted): `F_dyni(t) = -aP_pre·P_post(1+dP_d) + bP_post + cP_post·P_d` with weight update `dW_i/dt = F_dyni(t) - eW_i(t)`. Resolves STDP "conundrum" via two-level cross-correlation: (i) pre × post; (ii) post × dendritic-aggregate. Dendritic activity `P_d = Σ_i G_i P_post_i` is a *graph-aggregation operation* over the dendritic tree.

10. **Theta-phase-locked plasticity** (Sgritta et al. 2017 PMC6596728 PDF-extracted): STDP at cerebellar input stage *requires* 6–10 Hz theta-band phase-locking. Random pairing abolishes plasticity (PMC6596728 finding). 60 pairings at 1 Hz / 6 Hz / 10 Hz tested. Theta-phase coupling binds learning across cerebellar-cortical-hippocampal circuits.

11. **Connectome-harmonic decomposition** (Lioi et al. 2021 PMC8233110 PDF-extracted): explicit graph-Laplacian `L = D - W` (combinatorial), `L_n = D^{-1/2} L D^{-1/2}` (normalised), `L_rw = D^{-1} L` (random-walk) on cortical connectivity. Eigendecomposition `L = UΛU^T`; graph Fourier transform `X̃ = U^T X`. Low-eigenvalue eigenvectors = low-spatial-frequency cortical activity patterns (smooth across graph); high-eigenvalue eigenvectors = high-spatial-frequency. Default-mode network anchors low-frequency harmonics.
