### §3.2 Framework derivation of conformal dimension

Standard AdS/CFT mass-dimension relation (Maldacena 1997 arXiv:hep-th/9711200; Witten 1998 arXiv:hep-th/9802150 §2.2): for AdS_5 boundary d = 4,

```
m² L² = Δ (Δ − 4).
```

Chiral primary s_k modes (Kim-Romans-van Nieuwenhuizen 1985, Nucl. Phys. B 255, 63, by-ref per APS/Elsevier ToS) give

```
m² L² = k (k − 4),  k ≥ 2 (BPS-unitarity bound).
```

Solving Δ² − 4Δ − k(k−4) = 0:

```
Δ = 2 ± √(4 + k(k−4))
  = 2 ± √((k − 2)²)
  = 2 ± |k − 2|.
```

The unitarity branch (Δ ≥ 2) gives **Δ = k** for every integer k ≥ 2.

**Critical framework observation**: the discriminant **4 + k(k−4) = (k − 2)²** is a **perfect square at every integer k**. This is a Class N rational identity (closed-form). The √ operation reduces to integer arithmetic |k−2|. **No approximation, no continuum operation, no π.**
