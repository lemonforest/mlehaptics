## How to think about it (the analysis method)
1. **Coupling field = the weighted Laplacian `L` (Class L).** Bodies = nodes (mass = weight), pairwise gravity = edge weights (∝ mᵢmⱼ/r²; near ⇒ large). `laplacian.dense_laplacian(n, edges, weights)` assembles all pairwise forces into the discrete force/potential operator — the "gravity metric" as a relationship encoding.
2. **"Forces of forces" = iterated `L`.** Apply `L` again → `L²` = the discrete **biharmonic** (tidal / turbulence / bending). `Lⁿ` = the n-th-order coupling = the framework's recursion (F912) at the *force* level. **`Mat.__matmul__` ships** (`L @ L`), so this needs no new primitive — and the **eigendecomposition does it for free**: `Lⁿ = V Λⁿ Vᵀ`, one eigensolve gives all orders.
3. **Resonances / flux-lock = integer eigenvalue ratios (Class J + N + I).** The Laplace 1:2:4 lock is a **2-adic ladder in `Qprime`** (`{}`, `{2:1}`, `{2:2}`); real periods deviate slightly = the **libration** around the resonance, caught by `best_rational` (N). Integer ratio ⇒ resonant/flux-locked (Io's tidal heating); irrational ⇒ non-resonant/stable. Read the eigenvalue spectrum's ratios via `Qprime`/`best_rational`/`cyclic`.
4. **Directed flux = `magnetic_laplacian` (C/K) + `Qarg`.** Net angular-momentum / flux flow between near bodies is *directed* → the magnetic (complex-Hermitian) Laplacian; `Qarg` reads the phase = the flux direction. (F926: C/K-directional's home is flow graphs — this is one.)
5. **Orbital dynamics = `kepler` (Class K):** `equation_of_centre` / `kepler_solve` / `pin_slot` (the equation-of-centre IS the Class-K pin-slot epicycle). Direct coupling score = `coupling.signed_sum_squared` (K∘L).
6. **Turbulence = the spectral cascade:** low eigenmodes = large-scale bulk orbits; high eigenmodes = small-scale flux. Turbulence = energy flux *down* the spectrum (large→small modes); `L²` is the dissipation/viscous operator. The spectrum stratifies the scales (F781).
