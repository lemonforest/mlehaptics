## The marriage (the build)
- **CONTENT** = order-free Klein-4 **bag** of byte-composed word vectors → *which* words (the meaning). Order-blind (sim 1.000 for any permutation).
- **ORDER + grouping** = the **octonion coupling-walk**: `word_oct(w) = ∏ byte_oct(bytes)` (a word IS a byte coupling-walk), `sentence_oct = ∏ word_oct(words)` (a sentence IS a word coupling-walk). Non-commutative = order; non-associative = grouping (F863).
- **Generator** = greedy autoregressive walk: content proposes the candidate words; the coupling-walk picks the order by stepping toward the stored order-trajectory (octonion distance), **O(n²)** — reproduces `dog bites man`.
