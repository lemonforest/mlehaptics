## The reading (why the peak beats the full QDFT here)
- **The target is a SPIKE, so the peak is the matched filter.** In the single-rung fold, next `b` is stored at exactly one rung `r0`, so its cross-rung response `s_r(b)` peaks at `r0` and is noise elsewhere. The **max-over-rungs** read takes only the peak — it *rejects* the off-rung noise. The **full complex QDFT** sums over all rungs with the twiddle — it *includes* every off-rung noise sample coherently. By Parseval a spike's spectrum is flat (`|X_k|` = the peak for all `k`), so the QDFT gains *nothing* from coherent combination and *loses* the noise-rejection the max provides → it is worse (53→51, 58→49).
- **The elliptic win is a noise-floor effect, not a coherence effect.** F1000's elliptic +6pp came from the elliptic structured code giving a *lower, coherent* wrong-candidate max-of-noise (better peak SNR) — a property of the **max read**. The full QDFT does not use the max; it uses coherent combination, which the single-rung spike does not benefit from — so the elliptic advantage vanishes (49% < 51%). This *sharpens* F1000: the elliptic advantage is real, but it lives in the **matched-filter/peak** read, not the full transform.
- **The full QDFT's coherent gain needs SPREAD encoding (the honest boundary).** Coherent phase combination (√NR processing gain) helps only when the symbol is *spread across rungs* (CDMA/spread-spectrum), not stored at one rung. The F995 fold is single-rung, so the peak is optimal and the full QDFT is over-engineering. A genuine spread encoding (each next modulated across all rungs by its code) is the *only* regime where the full complex QDFT would beat the peak — a different, larger-storage scheme, and the honest next question if it is worth it.
