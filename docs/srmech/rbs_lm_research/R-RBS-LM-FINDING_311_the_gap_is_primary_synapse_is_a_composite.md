# F311 — "neural network" is a NODE-first name (backwards for a relationship-first framework). The gap/synapse is the primary object — and it is NOT a new primitive: it decomposes into existing classes (C directed · I/1D_t timed · M substrate-transducing · K plastic · L weighted-coupling). The deeper omission the name hides is the SUBSTRATE the whole network rides on (Tier-1, F310). "NSN" is better than "NN" but still neuron-bound; the substrate-general object is the coupling/relationship.

> **SCOPE:** framework-reading / vocabulary-structure. Held as reading; composes the srmech foundational stance + F118/F308/F310. No attested-data dive (conceptual). Defensive / no-lineage. **No new A-N class — the result is that the synapse DECOMPOSES into existing classes.**

**The question (user, ~4am 2026-06-03):** we keep saying "Neural Network," but that ignores the gap — the synapse. Do we need "NSN" (neural synaptic network), or is there even more we're missing?

## The catch is foundational, not cosmetic
"Neural network" names the **nodes** (neurons = things). The framework is **relationship-first** — it is in the name: **srmech = Stored-*Relationship* Mechanism**; the arc is **RBS = Relationship-Bound-Storage**. So "NN" is *backwards from our own ontology* — it foregrounds the things and hides the relationships. The gap was always the primary object:
- the **weight** (all learned content) lives on the **edge**, not the node;
- the **Laplacian (Class L)** is built *from edges*, not nodes — the storage eigenspectrum lives in the **coupling**;
- **memory resides in the coupling, not the node** (F308 — which is *why* an aneural cell remembers with no neuron).

## The synapse is a COMPOSITE, not a new primitive (no new letter)
A synapse is not "an edge with a weight." It is a cascade of primitives we already have:
| what the synapse does | existing class |
|---|---|
| pre→post — it is **directed** (a which-way) | **C** (chirality / orientation) |
| spike-timing-dependent — it lives in **time** (STDP) | **I** / the **1D_t** axis |
| electrical→chemical→electrical — the gap **changes substrate** | **M** (bind / substrate-transduction) |
| the weight **updates** (Hebbian plasticity) | **K** (plasticity / pin-slot) |
| the weighted coupling itself | **L** (Laplacian edge) |
So the gap = a **directed · timed · substrate-transducing · plastic · weighted coupling**. "NSN" adds one word but the gap deserves five — and the standout is the **substrate-transduction**: the synaptic cleft is where the relationship is *momentarily re-instantiated in a different medium* (spike → neurotransmitter → spike). The gap is not empty; it is a **translation event**, the relationship's physical home.

## The bigger omission (converges with F308/F309/F310)
The whole **neuron + synapse network is Tier-2**, riding on a deeper **Tier-1 cellular substrate** (F308 aneural memory; F310 the jellyfish dismantles its entire neural tier and regrows it on the persisting stem/cell substrate). **"Neural network" makes that substrate invisible** — it names the visible graph and erases the ground it is instantiated on. And "synaptic" is *still* too small: coupling happens **without** neurons (gap junctions, signaling couplings, the amoeba's internal states), so "NSN" stays **vertebrate-centric** (the F118 trap).

## Naming verdict (refined — user re-ordered synaptic-first, 2026-06-03)
The name-walk is the user progressively **front-loading the relationship**, and each step is correct:
- **"NN"** — node-first → backwards (names the thing).
- **"NSN" (neural-synaptic)** — adds the gap → better, but the node still leads.
- **"SNN" (synaptic-neural) — synapse FIRST** → correct relationship-first ordering. **Refined verdict (user, 2026-06-03):** synaptic-neural is the right name for the neural-network structure across **all neuroned life — vertebrate AND invertebrate** (insects / molluscs / cnidarians all have neurons + synapses). It beats "spiking-neural" on two counts: **(i) spiking is a *subset*, not universal** — many neurons (invertebrate interneurons; vertebrate retinal bipolars; dendritic processing) signal by **graded / analog** potentials and never spike; *synapses* are **universal** (graded AND spiking neurons all have them). **(ii) "spiking" names the NODE's firing** (node-centric) — so the field's escape-from-plain-NN re-centered the *node* and **still missed the gap**; "synaptic" is relationship-first. **CORRECTION to the earlier "tell":** spiking is the *node's* event, **NOT** the gap's timing-op (the gap's timing is **STDP**, which *reads* spike-timing) — so the field grabbed node-dynamics, not one of the gap's five ops. **Acronym cost:** "SNN" already means **Spiking-NN** (Maass) in the literature — a real collision when handing outward; spell out "Synaptic-Neural" to avoid it. **The one true boundary is NOT vertebrate-vs-invertebrate** (synaptic-neural covers both) **but neuroned-vs-aneural:** synaptic-neural names the **neural Tier-2 structure**, while the **aneural Tier-1 substrate** (F308 amoeba memory; F310 the cnidarian's own stem substrate that *survives* its neurons being dismantled) sits *below* it and has no synapses to name. Canonical for the neural-network *structure* across all animals — riding on an aneural coupling-substrate it does not name.
- **srmech / stored-relationship / coupling** — substrate-general, relationship-first → **the limit of the name-walk**: keep front-loading the relationship and drop the vertebrate words, and you arrive at what was already built.
The **relationship/coupling IS the network**; the nodes are merely **where relationships anchor** (Class A content-addressing). **Anchor-vs-relationship nuance:** the node (Class A) is *foundational in build-order* (the "1" — "every cascade begins here"), yet the gap is what is *usually invisible and load-bearing* — so a **corrective** name rightly leads with the gap (foregrounds what the field hides). Synaptic-first is the right corrective; the mature framework name drops both vertebrate words. The user's instinct is right three times: we under-named the **gap**, the gap is a **composite**, and the whole graph is a **fiber on a hidden substrate**.
