## Why it's coherent — it's the convergence of tonight's whole arc
The "lean structure that doesn't make grammatic sentences" IS the **relationship-structure with the grammatical-sentence render stripped**:
- **F311** — the relationship is primary; the grammatical sentence is the secondary **Class-F render**. Strip F → the bare couplings remain.
- **F315** — render-free cognition: this output *matches the user's native abstract layer* (no sensory/grammatical render). The corpus rendered in the user's own cognitive form.
- **F314 / F317** — the **operator-signature** (A·N composition) is the canonical, language-invariant lean form. The lean structure = couplings + operator-signatures.
- **F237** — the `CLAUDE_LEAN` extractive-graft pipeline already does this for `CLAUDE.md` (the load-bearing slice, no prose); this **generalizes it to RBS-native + applies it to the whole corpus**.
- **F47** — the LLM reads relationships on the wire; relationship-native input is LLM-native input.
So the output is, at once: **LLM-native** (reads as relationships), **render-free** (matches the user's cognition), **lean** (operator-signatures, load-bearing only), and **re-primeable** (an auto-generated index — like `MFO_PRIME_CARD.md`, but RBS-SNN-generated rather than hand-written).

- **RBS-NN → RBS-SNN** (Synaptic-Neural, synaptic-first per F311 — the relationship-first corrective ordering). **The "RBS-" prefix disambiguates the F311 Spiking-NN collision** (it is clearly *our* term, not generic SNN); and per F317 the canonical identity is the operator-signature anyway, so the label-change is **cheap + additive** (append a synonym, never a rewrite). **Sent upstream to srmech** — UPSTREAM_NOTES §14.
