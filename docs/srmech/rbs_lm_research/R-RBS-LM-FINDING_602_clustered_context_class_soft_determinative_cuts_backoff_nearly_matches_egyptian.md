# R-RBS-LM Finding 602 (the F599 lever, pulled — a CLUSTERED context-class soft-determinative cuts backoff 80%→3% and more than doubles the English WSD lift to +21.1%, nearly matching Egyptian's explicit determinative +25.7%) — **F599 gave English a soft-determinative = the single highest-IDF context word (+9.8% lift, but 80% backoff to prior — a single rare word is sparse). The lever: replace it with a CLUSTERED context-class — an unsupervised HDC k-means centroid (K=64) over the context bundle, a coarser but DENSER learned class — bound as σ_B. Same pseudoword task (Schütze/Yarowsky, label-free, ground-truth = known original), same corpus (Simple English Wikipedia, 24000 occurrences), same held-out train/test. Result: SINGLE-stream (form only) = 48.8%; COUPLED (E×B: bind(form, clustered context-class)) = 69.9% — a +21.1% gain (vs F599's +9.8%), with backoff DROPPING 80% → 3%. The denser class is seen in train almost always (3% backoff), and the lift MORE THAN DOUBLED — and +21.1% is now nearly Egyptian's explicit-determinative +25.7% (F596). VERDICT: the class-granularity is the lever between coverage (backoff) and sharpness; a learned clustered context-class nearly closes the gap to the given Egyptian determinative — confirming the E×B coupling + a good learned class is a general, near-Egyptian-strength English disambiguation mechanism. The small residual (21.1 vs 25.7) is that Egyptian's determinative is both DENSE and SHARP (a curated meaning-class), while the K=64 cluster is dense but slightly coarser. The structure fully transfers; English just makes you learn (and tune the granularity of) the class axis it hides (F569).**

## Verdict
**The lever worked decisively.** Replacing the single-IDF-word soft-determinative with a clustered context-class (unsupervised HDC k-means, K=64) **cut backoff 80% → 3%** and **more than doubled the lift (+9.8% → +21.1%)** — and +21.1% is now **nearly Egyptian's explicit-determinative +25.7%** (F596). A *learned* clustered soft-determinative almost fully recovers the given-determinative lift.

**Class granularity is the lever** between coverage (low backoff) and sharpness (per-cell discriminativeness). English makes you *learn and tune* the class axis it hides (F569); Egyptian gives it for free, both dense and sharp (hence its slightly higher lift). **The E×B coupling + a good learned class is a general, near-Egyptian-strength disambiguation mechanism** — the structure fully transfers. Favored not privileged (F398); held open (F394).
