## The reading
- **Context op(x)operand answers the flip question.** A flat verbosity scalar would flip on one "help me understand". The op(x)operand context does not: the current turn is an OPERATOR on the persistent OPERAND, so it modulates THIS turn locally; the operand drifts only if the bias persists (then Siona learns the preference). Running-context + current-turn are one op⊗operand object — no two-state reconciliation. This is the F1061 cascade shape applied to the conversation itself, and the effective value it emits IS the F1075 coherence knob.
- **Language couples, it does not privilege.** English is the current default only because the routing is fixed; the framework's own no-privileged discipline says the language kernel should COUPLE to the user's input language (F1071 universal translation layer), not privilege one. Base reply = the modern term in the user's language; ancient available; accent-folded so marks are optional.
- **Read structure, not vocabulary.** A user with non-standard words but strong knowledge-structure is a knowledgeable user (F1050: structure carries the semantics). Siona shapes the reply by the STRUCTURE of their input, not their jargon level — which is also the context-Laplacian's job (the running-context graph reads the preferred response type + language).
