FRAME. A frame F is (unbounded integer index n, stage map n -> F(n), limit object X) with F(n) -> X.

CORRESPONDENCE LEVELS between frames A and B (a property of STAGES, never of rates):
  L3 EQUALITY    : there is a strictly increasing integer map f with A(n) == B(f(n)) as objects, for every tested n.
  L2 PROJECTION  : there is f and a fixed family of coordinate projections pi_n with A(n) == pi_n(B(f(n)))
                   (or with A and B swapped), for every tested n.
  L1 JET         : in one common graded coordinate system, A(n) and B(f(n)) agree exactly on a coordinate set
                   that grows without bound with n, and neither is a projection of the other.
  L0 LIMIT ONLY  : none of the above.
"Exact finite-stage correspondence" (ESC) is read two ways and H is tested under both:
  ESC-weak = L >= 1 ; ESC-strong = L >= 2.

COMMENSURATENESS, two definitions, both fixed now:
  Def R (per-step rate). Step class of a convergent frame: LINEAR with root rate r = limsup eps(n)^(1/n) in (0,1);
    SUPERLINEAR with order q = lim log eps(n+1)/log eps(n) > 1; TERMINATING (eps(n) = 0 at a finite n); DIVERGENT.
    A pair is R-commensurate iff same class AND log r_A/log r_B in Q (linear) or log q_A/log q_B in Q (superlinear).
    Cross-class pairs are R-incommensurate. A pair containing a terminating or divergent frame is R-UNDEFINED.
  Def B (shared base). If eps(n) = C * beta^(s(n)) * (subexponential factor) with s an integer schedule, the pair is
    B-commensurate iff log beta_A / log beta_B in Q, whatever the schedules. UNDEFINED where no such form exists.
  Irrationality is decided only from closed forms (unique factorisation; Lindemann-Weierstrass, CITED-NOT-FETCHED).
  A float ratio alone yields UNDECIDED, never a verdict.

HYPOTHESIS H (CANDIDATE, from the brief): ESC <=> commensurate.

  Tested in all four cells (Def R, Def B) x (ESC-weak, ESC-strong). Definitions are not to be changed after results.
