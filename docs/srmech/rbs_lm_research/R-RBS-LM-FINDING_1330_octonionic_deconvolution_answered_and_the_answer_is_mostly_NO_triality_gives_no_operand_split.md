## 1 — the 2-vs-3 operand boundary `[re-verified here]`
```
  inverse property   conj(a)·(a·b)     == b      : True    <- division exact at 2 operands
  through a third    conj(a)·((a·b)·c) == b·c    : False   <- and broken at 3
```
Artin's theorem: the subalgebra generated by **any two** elements is associative. So `a⁻¹(ab) = b` and `(ab)b⁻¹ = a` hold exactly. **The Moufang identities are the exact strengthening that survives one *repeated* element inside a bracket — they require the repetition.** In a deconvolution setting the three elements (signal, kernel, inverse-kernel) are **distinct**, so Moufang buys nothing beyond the inverses we already had.

> **2 elements → group-like. 3 distinct elements → nothing.** That is the sharp boundary, and it is where the deconvolution idea dies.

## 2 — the solution variety is trivially fibered `[ATTESTED / derived-from-attested]`
`μ: S⁷ × S⁷ → S⁷`. The shear `Φ(a,b) = (a, ab)` has inverse `(a,c) ↦ (a, a⁻¹c)` — well-defined by the inverse property — so **`μ` is a *trivial* bundle, isomorphic to first-factor projection.** Fiber `μ⁻¹(c) ≅ S⁷ ≅ Spin(8)/Spin(7) ≅ Spin(7)/G₂`, **dim 7**; general case `dim_ℝ = 8`.

**No twisting to exploit.** One operand is a free parameter, full stop.
- The **agent flagged this as derived-from-attested, not a cited theorem** — it follows immediately from division + the inverse property, but no source states it in this form.
- **Do not conflate with the Hopf fibration.** `S⁷ ↪ S¹⁵ → S⁸` (Hopf invariant 1, Adams 1960) is the *Hopf construction applied to* `μ`, a different map. Both true, different objects.

## 3 — the attested null on triality `[the finding that closes #228's premise]`
Cartan's principle (Lounesto §5, verbatim): `Ǔ₀(x ∘ y) = U₁(x) ∘ U₂(y)`, with `(U₀,U₁,U₂)` a triality triplet. Real, exact, textbook.

**But it does not invert anything.** It says *if the product moves by `U₀`, the operands move by `(U₁,U₂)`* — a covariance law. `Spin(8)` acts transitively on the target `S⁷`, so equivariance reduces recovery to a single fiber, which §2 shows is still 7-dimensional. **Determining `(U₁,U₂)` requires already knowing `U₀` — i.e. already knowing how the operands moved.**

## 4 — the practical crux: transform-domain division is broken `[ATTESTED]`
Błaszczyk's OFT convolution theorem (arXiv:1905.12631, Thm 16) is **not** `F{u*v} = U·V`. It couples the **8 parity components** of one factor to the other factor evaluated at **four sign-reflected frequency points** `(±f₁,±f₂,±f₃)`. Recovery at `f` is an 8×8 system coupled across a sign orbit. The author's own verdict, verbatim: *"in general the above complicated form this claim is of little use."*

**The fix and its exact price.** Pass to the quadruple-complex algebra `F` — same 8 real components, re-bracketed, **commutative and associative** — and `V(f) = H(f) ⊙ U(f)` holds classically. But `F` has a non-invertibility locus `δ = 0`, and:

> **You cannot have all three of (i) 8 real dimensions, (ii) commutative + associative, (iii) no zero divisors. 𝕆 buys (i)+(iii); `F` buys (i)+(ii). Deconvolution needs (ii), so it pays in zero divisors.**

**The agent caught an error in the preprint** and verified it in exact rationals from the paper's own multiplication formula: Błaszczyk asserts *"there are no zero divisors in F"* — but `(1 + e₆) ⊙ (1 − e₆) = 0`. Consistent with theory (a finite-dimensional commutative associative ℝ-algebra without zero divisors must be ℝ or ℂ). **Verified against arXiv v1 only** — the published version is paywalled and may have corrected it.
