## Honest ceiling — order lifts but does not close

The absolute frame accuracy (0.279) is a lift, not a solve: many grammatical slots are genuinely locally ambiguous ("in ___ house" fits the/a/his/her/this), so exact placement needs longer-range agreement AND the content the operand carries — which a bigram canon does not have. So order does substantial real work (2.8×) but the residual is the genuine local ambiguity + the content-dependence, which routes back to the operand / the expert (F282). The two grammatical levels are now separable and BOTH measured: vocabulary (bag, F1191, set-recall 0.337) and placement (order, F1192, 2.8× over bag) — order is what unlocks placement.
