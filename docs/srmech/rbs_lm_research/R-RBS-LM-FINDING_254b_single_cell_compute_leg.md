## §1 The evidence, ranked on F254's axis (cell-autonomous compute vs compute-requires-multicellularity; both poles held)

**TIER 1 — cleanly supports cell-autonomous compute (true mononucleate single cells):**
- **Decision hierarchy** — *Stentor roeseli*, Dexter/Prabakaran/Gunawardena 2019: stereotyped escalating avoidance (bend → ciliary alteration → contraction → detachment), later responses recruited only after earlier fail, terminal choice "consistent with a fair coin toss." Genuine sequential decision-making in one cell. **NOT learning** (authors explicit).
- **Non-associative learning (habituation)** — *Stentor coeruleus*, Rajan/…/Marshall 2023: meets Thompson–Spencer hallmarks (stimulus specificity, frequency/intensity dependence, spontaneous recovery); mechanism = a **single step-like binary switch** (two-state stochastic machine), not gradual decline; population gradation = distribution of switch times. **The strongest single-cell LEARNING datum** (habituation is the accepted-as-real category AND it is a true mononucleate cell).
- **Cell-intrinsic STATE-PERSISTENCE** — Walters 2012 (hyperexcitable state persists in dissociated low-density culture); **Bavencoffe/Walters 2024 (peer-reviewed)** cAMP→PKA→CREB→transcription→protein-synthesis LTH in isolated nociceptors (memory-consolidation machinery, no synapse); CPEB prion-like self-templating (Si/Kandel; Bogen 2012). **Strong — but state-persistence/hysteresis, a DIFFERENT sense from learning.**

**TIER 2 — supports cell-autonomy WITH a load-bearing caveat (the Physarum cluster):**
- Maze-solving (Nakagaki 2000 — optimization, *not* learning), habituation + spontaneous recovery (Boisseau 2016), memory-transfer-by-fusion (Vogel & Dussutour 2016). **Caveat (authors' own): Physarum is a MULTINUCLEATE acellular syncytium** — single-cell by membrane, not by genome-copy; the integrating unit is debated; no independent replications identified.

**TIER 3 — contested / does NOT cleanly support (skeptical pole at full strength):**
- **Associative/Pavlovian single-cell learning** (Gelber 1950s *Paramecium*; Hennessey 1979; Armus 2006): foundational claims **largely unreplicated/confounded** (Katz & Deterline failed to replicate Gelber; Jensen's thigmotropism/bacteria alternative; Armus counterbalance confound). **Gershman et al. 2021 argues *for reconsidering*** (Gelber "convincingly demonstrated" Pavlovian conditioning) — but this is a **reinterpretation, not new data, against consensus.** The 2026 Stentor associative result is a **non-peer-reviewed preprint.** Field consensus 2024–26: **non-associative single-cell learning = real; associative = unsettled.**

## §2 The load-bearing discipline: LEARNING ≠ STATE-PERSISTENCE (the merge kept them strictly separate)

The merge refused to conflate two senses of "cell memory":
- **LEARNING** = stimulus-contingent *acquisition* (habituation; the contested associative claims).
- **STATE-PERSISTENCE / hysteresis** = *survival* of an already-induced functional state (Walters HSA, Bavencoffe LTH, CPEB self-templating, epigenetic transcriptional memory).

The vertebrate anchors (Walters/Bavencoffe/CPEB) are **state-persistence, not learning** — strong and mechanistically grounded, but they show a cell *holds* a state, not that it *acquired* it by experience in the dish. This distinction is what keeps the F254 verdict honest: cell-autonomy is best-supported for state-persistence + habituation + decision, and is *not* established for associative acquisition.

## §3 Falsifier verdict (the point of the leg)

F254's stated falsifier **(F-a): "compute genuinely requires multicellularity — impossible in a single cell."**
- **NOT triggered.** No verified result shows learning/decision is impossible in one cell; the opposite holds (Stentor decision + habituation in a mononucleate cell; cell-intrinsic state-persistence in isolated vertebrate neurons). **Current evidence leans cell-autonomous for the weaker senses.**
- **The live risk, stated plainly (no leaning):** if F254's "compute" is meant to include **associative/predictive** learning, the single-cell literature is **silent-to-negative** — a clean, replicated, peer-reviewed associative-learning result in a true mononucleate cell **does not currently exist** (the 2026 preprint would change this if it replicates). So F254 is **supported for non-associative compute, at genuine risk for associative compute.**
