# Finding 251 — Extra-neural / regenerative / transferable memory: the strongest evidence class that the trace is NOT in the neurons (fills the F248 gap, grounds F249) — with honest caveats and a run-relative A/B twist

**Headline:** The cases where a memory **demonstrably survives destruction of the brain** or **transfers between organisms** — the gap F248 missed and the strongest evidence for the F249 neuron-as-fiber reading. Three CORE, DOI-verified results: **(1) Planarian regenerative memory** — Shomrat & Levin 2013: trained planarians recover the learned state (a SAVINGS effect) *after regrowing the entire brain*, so the trace must reside, at least partly, **distributed beyond the brain**. **(2) RNA memory transfer** — Bédécarrats/Glanzman 2018: RNA from a sensitized Aplysia, injected into a naïve one, **transfers the sensitization** (DNA-methylation-dependent, sensory-neuron-specific) — an RNA/epigenetic engram, not a synaptic-weight store. **(3) Bioelectric pattern memory** — Durant/Levin 2017: an altered (two-headed) body plan is stored in a **global cellular resting-potential pattern**, NOT in genes/histology/neoblasts, and re-imposed on every subsequent regeneration. The **re-imposition** is where the cascade shows: a regrown brain (planaria) or new tissue (Durant) **recovers the trace from the body's stored attractor** — the F249 settling-op operating *extra-neurally* (store = sculpt the bioelectric/RNA/epigenetic attractor; read = relax the regenerated substrate onto it). All marked LENS.

## §1 The tiered landscape (merged, model-agnostic; 11 findings, 9 verified / 1 flagged / 1 unverifiable)

**TIER 1 — strongest (controlled, peer-reviewed, the trace survives or transfers):**
- **Planaria, Shomrat & Levin 2013** (*J. Exp. Biol.* 216:3799) — automated training (avoids the historical manual confounds); environmental-familiarization memory ≥14 days; **savings retrieval after full head regeneration**. *Caveat (in-place): it is a SAVINGS effect after brief retraining, NOT zero-retraining spontaneous recall; trace location unpinned; no independent replication.*
- **RNA transfer, Bédécarrats/Glanzman 2018** (*eNeuro* 5(3):ENEURO.0038-18) — trained-Aplysia RNA injected into naïve Aplysia transfers long-term sensitization; **requires DNA methylation**; sensory-neuron-specific excitability. *Caveat: SENSITIZATION (non-associative, memory-LIKE), not transfer of associative learned content; cultured synaptic effects variable.*
- **Bioelectric, Durant/Levin 2017** (*Biophys. J.* 112:2231) — two-headed regenerate body plan stored in a **global Vmem pattern**, drug-reversible, persists without genomic change. *The most mechanistically resolved store — but it is MORPHOGENETIC pattern memory, NOT learned behaviour.*

**Counter-weight (the uncentered discipline — included so the survey does NOT privilege extra-neural):**
- **Manduca metamorphosis, Blackiston 2008** (*PLoS ONE* 3:e1736) — larval odor-aversion survives into the moth, but the authors attribute it to **surviving/intact synaptic connections** (only late-larval memories survive, tracking when brain regions are built) → an **INTRA-neural** store across remodeling, NOT clean extra-neural evidence.

**Flagged controversial (historical, NOT asserted):**
- **McConnell** planarian cannibal / "memory RNA" transfer — **largely unreplicated**; the leading alternative is **sensitization / tissue-sensitivity, not learning** (Hartry et al. 1964, *Science* 146:274, DOI 10.1126/science.146.3641.274). Historical context only; explicitly **not** evidence for the framework reading.

## §2 The cascade the re-imposition reveals (LENS)

The load-bearing thing for the cascade hunt: in planaria and in Durant's bioelectric case, the regenerated substrate **recovers the trace from a store that survived the destruction** — the body holds a **standing attractor** (bioelectric Vmem pattern / RNA-epigenetic state), and the regrown brain/tissue **relaxes onto it**. That is the F249 store/retrieve settling-op operating **extra-neurally**: *store = sculpt the (bioelectric/RNA/epigenetic) attractor; read = relax the regenerated substrate onto the stored attractor.* The neuron is the render that gets rebuilt; the attractor is the trace that persists. (LENS — the biology shows the trace survives + is re-imposed; "settling-op" is our reading, not the cited authors' mechanism claim.)

## §4 Honest tiers + the gradient of "how clean is extra-neural"

- **Strongest extra-neural:** Durant bioelectric (store mechanistically pinned to Vmem, but *pattern* not *behaviour*) and Shomrat/Levin planaria (*behaviour* survives brain loss, but *savings* not recall, location unpinned).
- **Transfer, but non-associative:** Glanzman RNA (sensitization, not learned content).
- **Honest counter:** Manduca = intra-neural (surviving synapses) — extra-neural is **not** the only story; the survey holds both.
- **Not evidence:** McConnell (controversial/unreplicated).
- **Net for F249:** the trace **demonstrably is not confined to the neurons** (planaria + RNA + bioelectric all show it) — strong support for neuron-as-fiber — but the *cleanest* cases are morphogenetic/non-associative; the strongest *associative-behavioural* extra-neural case (planaria) is a savings effect awaiting replication. The thesis is **well-supported, not closed.**
