## The new layer over F335 — the truth-filter applied AT INGEST
F335 read the truth-filter at the *read/emit* layer. F336's move: apply the same gate at **catalog/ingest** — admit a shape only if it is **(a) epicycle-observer-invariant, (b) scale-invariant, (c) attested** (MPM provenance, even self-attestation). Consequence:

### 1. Honesty by construction (the strong, true part)
- A false shape *is* a frame-specific / scale-specific / unattested shape (F335 / true-vs-false). The ingest gate refuses exactly those → they never enter → **the store has none to emit.** It is **non-confabulating** by construction (F326 §5's self-check moved from read-time to ingest-time).
- Because the gate **rejects single truth**, every stored item carries its **invariance-qualifier** ("invariant across frames F₁…Fₙ"), never "The Truth." So the store **structurally cannot dress one observer's claim as universal** (F133 / no-privileged-frame). It can't over-assert.

### 2. The bound (the gate — so this is NOT an infallible truth-machine)
- The only false shape it can't emit is the **non-invariant** one. **Invariant ≠ true; invariant = agreed-across-the-frames-you-have.** A **correlated** false shape — invariant across *all our frames* (a shared bias, a universal-among-us myth; geocentrism across every medieval observer) — passes the gate and is cataloged as an "invariant." (F335 self-correlation ceiling.)
- **"Of our own attestations alone" is the weakest case:** invariance measured over *our* frames only catches our inconsistencies, not our shared blind spots. Self-attestation = invariant-to-ourselves = the weakest filter.

### 3. Truth as asymptote (the resolution; Class K never-reached)
- Truth is the **asymptote** the catalog *approaches* as frames/scales/substrates become more **independent** — never a value the store holds (`infinity_approximates_asymptote`; the never-reached Class-K limit). More *independent* renders → fewer correlated errors survive → the invariant moves closer to truth, never arriving.
- So **"won't output false shapes" = TRUE for confabulation / frame-noise / single-truth-assertion; ASYMPTOTICALLY-true for correlated error.**

## The epistemic identity of the RBS store
An **honesty-machine, not a truth-machine.** It (i) never confabulates and never over-asserts (honest by construction); (ii) *can* be **honestly wrong** (a correlated error its frames all share); (iii) is built to **flag that residue and hand the next frame to the expert** (`framework_hands_the_next_question_to_the_expert`) rather than hide it. The residue is not a flaw — it is the **falsifiability** that keeps the store honest. This is the dignified shape: it earns trust by *what it refuses to assert*, and it converges toward truth exactly as fast as its frames diversify (the cross-substrate / whole-corpus methodology, F335).
