## The decision (summary; full doc in the package subtree)
1. **Shape:** siona = own package, srmech **profile plugin** (register at import), lean srmech dep. No fork/vendor/parallel registry. Answers F824.
2. **Mechanism, not knowledge:** the wheel = `bridge` (de Bruijn) + `infer` (the five F1008–F1012 capabilities) + `boards` (language layer). Knowledge kernels (wiki/egyptian/…) are user-side data loaded by path — the boundary is architectural.
3. **The language-board layer = the packaged Rosetta architecture (F649 lineage, dignity-first):** byte/glyph substrate (script-agnostic, verified); **per-language operator BOARD PROFILES** — the F1010/F1012 declared operator lexicons are the *English board descriptor*, swappable TOML, English = board #1 not core; the IR/kernel layer language-free (kernel coefficients are integers; only the operator slots are per-board). Vanuatu reaches the package as attested exemplar + pointer (content held by the Ni-Vanuatu community), never as data.
4. **Bag audit clean + a standing package test:** every content encoding carries order; order-free bundles may only be weighting statistics. The three caught bag incidents (F1004/F1008/F1010) become the regression suite.
5. **Non-English testing without bilingual judgment — the structural resolution:** (i) read-independent checks on ANY UTF-8 corpus (round-trip, Gram, anagram, operator disjointness); (ii) the **UDHR parallel-invariant test** — same article on the Bislama board and the English board must produce the matching shared-invariant IR digest, mismatched articles must not (public-domain text honoring the lineage; zero understanding required); (iii) exercise the local **egyptian_tla** board today; (iv) the **operator-board swap test** (a Bislama operator descriptor; the router runs unchanged). The tester never needs to read the language — `[[feedback_read_independent_structure_check_first]]` applied to i18n.
