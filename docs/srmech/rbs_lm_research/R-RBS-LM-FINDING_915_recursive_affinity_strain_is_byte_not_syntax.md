## Reading (honest null)
**NULL:** the octonion associator-strain does **not** encode syntactic constituency. The strain is **byte-derived** (per F909 — the octonion affinity is byte-level), so it cannot select which *syntactic* bracketing is real. The F911 stability selection is over **byte-level molecular** stability, not grammar. Real constituency is **distributional/syntactic** — a different scale, exactly as F909 found for valence. The fundamental force (octonion byte-bond) lives below; linguistic structure (constituency, valence, syntax) lives at the distributional/resonator scale above. **Don't conflate the scales** — the recurring lesson (F905/F909/F911/F915).
