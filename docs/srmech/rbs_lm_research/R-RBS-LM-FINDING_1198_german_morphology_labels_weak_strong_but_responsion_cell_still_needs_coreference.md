## Reading — the morphology labels the axis, but the responsion cell is still coref-gated

1. **The label works (door 1's deliverable).** The weak/strong split is cleanly countable, and the full/strong form is the marked minority (~15–25%), matching Schwarz's prediction. So German genuinely SPELLS the axis English collapses — we got the weak/strong labels with no coreference.

2. **The validation FAILS — and the failure is the finding.** If strong = anaphoric, P(recent | strong) should be high; it is not (0.09–0.24, indistinguishable from weak). The cause is not that the distinction is unreal — Schwarz's contrast is experimentally established — it is that my "recent = same head-lemma within 200 tokens" is an inadequate proxy for "has an antecedent." Real anaphora uses a **non-identical** antecedent (pronoun / synonym / superordinate) or a distant one, none of which exact-lemma-recency can see. This is the **exact F1197 coreference wall**: lemma-repetition ≠ coreference.

3. **So door 1 does NOT sidestep door 2.** The German morphology frees the weak-vs-strong axis, but splitting STRONG into DETECT (real antecedent) vs RESPONSION (accommodation — strong morphology, no antecedent) requires **finding antecedents = coreference**. The responsion cell cannot be isolated with morphology alone. (Second confound, honestly noted: the contracted "weak" count is inflated by quasi-obligatory contractions — im/am/zum are the unmarked default — so the raw 80:20 is a markedness ratio, not a clean uniqueness estimate. Both confounds only surfaced by *running* it.)
