# R-RBS-SNN Finding 489 — **widening, not narrowing: the synapse may be a FUNCTIONAL (stigmergic) partition — a field-marking in the shared substrate between neurons — co-equal with F488's structural (intra-register slot) reading; chirality + the asymptote DEFINE the partition, and we hold both without collapse.** The user's brake (2026-06-07): "synapse might be a functional partition sort of like how colony insects can use the environment for marking … it's here because chirality and the asymptote define partitions, but we might also be overstating the previous comment, so we shouldn't narrow our perspective too early." F487/F488 located a real partition and a real chirality, but they framed the synapse as a **structural** sub-part of one neuron's register (the imaginaries e1..e7, the box's slots). The **stigmergic** reading is co-equal and biologically literal: a synapse lives in the **shared space between two neurons** — the pre-synaptic side **writes** a marking (transmitter release ≈ an ant leaving pheromone), the post-synaptic side **reads** it (receptor binding ≈ following the trail). That is **stigmergy** (Grassé 1959): coordination through a marked environment with no direct agent-to-agent channel. It maps onto the §0 foundation — **synapse = the field-marking (the shared substrate, the "two-truths" field), neuron = the local excitation** (DUALITY.md) — so the synapse is **between** registers, not inside one. **Chirality** (who-writes/who-reads = the directedness) and **the asymptote** (field vs excitation, held without collapse) are what *define* the partition; therefore both readings (structural slot ⊕ functional field-marking) are held **co-equal, favored not privileged** (F398), and F487/F488 are explicitly marked as possibly over-narrow.

## The two co-equal readings (the asymptote, not a collapse)
| | **structural** (F488) | **functional / stigmergic** (this finding) |
|---|---|---|
| where the synapse lives | inside one neuron's register (imaginaries e1..e7) | in the **shared substrate between** two neurons (the cleft / the field) |
| what writes / reads it | the neuron holds its own slots | pre-neuron **writes** a marking; post-neuron **reads** it (stigmergy) |
| §0 mapping | the neuron-object's box | **field-marking** (synapse) vs **excitation** (neuron) — the two truths |
| chirality | the conjugate flips the slot-imaginaries | the **direction** of write→read (pre→post) = the marking's handedness |
| the lattice stitch (#1 rung) | one register's carry → next's working (internal wiring) | the synapse **IS** the stitch — the shared-field trace coupling registers |

Both are true at once: a synapse is structurally a coupling AND functionally a marked trace in the shared field. The **asymptote holds them without collapse** — and which one is "the" synapse is exactly the kind of premature narrowing the brake forbids. **Neither is privileged** (F398); the partition is *defined by* chirality (the directedness) + the asymptote (field/excitation), not by choosing a side.

## Why this matters for the next rungs (it re-shapes #1)
The stigmergic reading puts the synapse **between** registers — so the **inter-register stitch (#1)** is not merely "wire A's carry to B's working." It is: **A writes a marking into a shared field; B reads that marking as one of its working synapses.** The synapse is the *field-trace*, the neuron the *excitation that marks/reads it*. The stitch is therefore itself a **directed (chiral) edge at the lattice level** (the same `i(A−Aᵀ)` magnetic-Laplacian chirality as F487 Test A, now between registers). The build (F490) uses this reading **while keeping the structural reading live** — testing whether treating the synapse as a shared-field marking makes the lattice stitch natural, *without* claiming it is the only truth.
