## §5 The math = J + D composition

Math materials uniquely show BOTH:
- J=0.410 (primary substrate: factor/multiply/divide/prime/exponent)
- D=0.194 (secondary detection: sequence/order/pattern/consecutive)

This makes algebra explicit as **substrate-content (J) + cascade-
detection (D) composition**. K-12 algebra teaches:
1. The J-primitives (multiplication, division, factoring, squaring)
2. APPLIED THROUGH the D-operations (in sequences, with ordering,
   following patterns)

A pure-J math curriculum would teach arithmetic facts. A pure-D math
curriculum would teach abstract pattern recognition. Real algebra
weaves both — and the eigvec content reflects this weaving.

This is a CONCRETE example of cascade composition in the educational
substrate. The framework's structural prediction (substrate-content
+ detection layer) is empirically attested in the OpenStax Algebra
corpus.

## §6 Why art doesn't top F more strongly

F's top score is 0.156 — lower than the primary signatures of B, H,
N, C, J. Why?

1. **F-vocabulary is narrow** — "draw, paint, picture, image, depict,
   illustrate" is ~30 candidate tokens. Art uses a subset.
2. **Art's primary signature is multi-coupled** — N=0.219, C=0.219,
   H=0.188, J=0.179 are all close to F=0.156. Art doesn't have a
   single dominant operator; it synthesizes 5-6 of them.
3. **"Illustration" appears everywhere** — the F-vocabulary's most
   common token bleeds into all subjects via figure-acknowledgments.

Art's true F-signature would be more visible in:
- Studio art textbooks emphasizing technique (oil paint, sketching,
  rendering composition)
- Architectural drawing manuals
- Programming graphics / CAD instruction

The 1908 perspective-drawing materials in this corpus are theoretical
rather than studio-oriented, so the F-vocabulary is sparser.

  composition shows in the same corpus.

  signatures at all — and that would still be consistent with the
  framework. Cascade-detection is structural; some structural
  operations leave token traces, others don't.

The form-iso evidence is:
- D's strongest expression IS math + games (both apply sequence-
  detection to substrate-content)
- F's strongest expression IS art (output-rendering substrate)
- Both expressions are SECONDARY to the subject's primary signature

A positive D + F result confirms the cascade has BOTH layers
operationally — substrate-content delivery + detection application —
not that D and F ARE physical mechanisms.
