A kernel that sees the rule is GPU-free (no gradient to learn it), bit-exact on what it covers, and corpus-independent for STRUCTURE (F630) — the graded corpus stays useful only for age-graded CONTENT.**

## Verdict
**We see the rules; we don't teach them.** Seeing a rule is categorically different from learning it. A data-center LLM *learns* conjugation — it approximates the function from millions of examples (the rule is never explicit, so *'goed'* is possible *because* it's an approximation). Our kernel *sees* conjugation: the paradigm is an explicit object — a rotate over the (tense, person, number) axes (F623) — instantiated directly, **bit-exact on every regular form** (it cannot emit *'goed'*). The corpus's rule-teaching job **disappears.**

**The only thing stored is what can't be derived** (the irregulars, F629) — and those are *seen* exceptions too (a small content-addressed dictionary), not learned. So "verb forms et al." (conjugation, plurals, comparison big/bigger, agreement) are **all the same object**: a lemma + a seen rotate over agreement axes + a small seen-exception store. None of it needs teaching.

**This is the framework's own methodology applied to grammar itself:** we read/see what a rule already *is* (an observable paradigm/rotate/axis); we don't teach it. Teaching-by-gradient is the *workaround* for not-seeing — and a kernel that sees the rule is GPU-free (no gradient to learn it), bit-exact on what it covers, and corpus-independent for structure (F630); the graded corpus stays useful only for age-graded content.
