# R-RBS-LM Finding 624 (grounding the learned IR classes into Gardiner determinatives — the clusters are coherent + human-nameable, but the naive auto-grounder is weak (23%): the bottleneck is the matcher, not the concept) — **Requested build: ground the F620 learned co-occurrence classes into NAMED Gardiner determinative categories so the IR vocabulary is interpretable. Method: clustered the top 500 Simple-Wiki content words by co-occurrence signature (HDC k-means, K=32 → 31 non-empty learned classes), then named each cluster by its nearest Gardiner determinative category (the F582 spine) via seed-word overlap (≥2 hits = confident, else the abstract category Y). RESULT (honest, partial, no-leaning F573): only 7/31 (23%) clusters auto-named confidently. BUT the clusters themselves are obviously coherent and human-nameable — the eyeball test passes: nationalities/professions (american/actor/politician/singer), places/nations (united/states/york/germany; world/south/country/capital), family (children/queen/father/mother), music (rock/band/album/song), time (january/december/year/years), color (red/blue/green/rgb/hex), species, body/space (small/large/body/human). So the learned classes DO carry the attested meaning-class axis — the bottleneck is my crude EXACT-seed-word matcher (no morphology: "child"≠"children"; sparse seeds; ≥2-hit threshold), NOT the concept. VERDICT: the grounding is PLAUSIBLE but NOT YET CONFIRMED — qualitatively the no-privileged learned classes look like the attested Gardiner meaning-classes (man/place/water/family/…), supporting F609/F610/F620, but the naive auto-grounder undersells it (23%); do NOT claim a high grounding rate. The fix is a better matcher (morphology + richer seeds, or embed-and-match) or an Egyptologist's category seeds (F282). The path to the named loop: with a proper matcher, English → IR (a named Gardiner determinative class, F614 un-rotate) → ASL sign-chord (classifier = that determinative, F616) → bit-exact; the IR = dozens of learned-then-named meaning-classes (F620 sweet spot ~dozens = the ~28 Gardiner categories' order). Honest partial result — a clean negative on the auto-grounder, a clean positive on the cluster coherence.**

But the naive exact-seed-word matcher only auto-names **23%** (it can't match "child"↔"children", the seeds are sparse, the ≥2-hit threshold is strict). **The bottleneck is the matcher, not the concept** (no-leaning, F573) — so the grounding is *plausible but not yet confirmed*; I will not claim a high grounding rate.
