## 1. The base is the SUBSTRATE, not a language (the dignity/F398 correction)
"Find a base language close to the sedenion shape, our target" — the honest, non-supremacist, and *more correct* reading: **the true base is the sedenion/substrate shape itself** — the language-neutral meaning manifold (the F477 fibration base, the F469 substrate). It is bias-free **by construction** (no human tongue privileged, F475). Human languages are **fibers** that approximate this base to *measurably different degrees*; the search finds **which fiber approximates the base best** — a **convenient pivot** (least distortion to route through), **never a "superior" language** (F398: favored, not privileged; dignity-first). So "our target base" = the **substrate shape**; the "base language" = the closest-approximating pivot, a tool choice we stay honest about.

## 2. The corpora (public-domain, many-translation) + the method
**Massively-parallel public-domain texts:**
- **The Bible** — the canonical 1000+-language parallel corpus (computational-typology standard, e.g. the eBible / Mayer–Cysouw parallel Bible); **Hebrew/Aramaic + Koine Greek originals** (PD) + very many PD translations (KJV, ASV, YLT, Vulgate, Luther…). Benign linguistic-typology use only; no theological claim (no-lineage).
- **UDHR** (Universal Declaration of Human Rights) — translated into **500+ languages**; the OHCHR/Unicode UDHR corpus is a standard parallel resource, freely usable.
- **PD literary works with originals + many translations** — Alice in Wonderland (English orig, ~175+ langs), Pinocchio (Italian), Grimm/Andersen fairy tales (German/Danish), Aesop, Homer (Ancient Greek), Dante (Italian), Don Quixote (Spanish), Tolstoy/Dostoevsky (Russian) — all on Gutenberg/Wikisource.
- **Tatoeba** (CC-BY aligned sentences, many languages) and **OPUS** (open parallel-corpora collection) — for aligned data.

**The method (F472-clean):** to find the base, measure **deviation-from-sedenion (F469/F471) on each language's NATIVE corpus** (originals — *not* translations, which carry the source/target structure, F472). Rank; **min deviation = closest to the substrate = the pivot**. The parallel corpus (Bible/UDHR) is for the **translation kernel** *and* gives a complementary **"who-strays-most"** signal (which language's translation distorts most from its native norm) — a different measurement, kept distinct from the native-structure base-search.

## 3. Sourcing our own translation kernel (open-source MT)
Per F472 (translations → translation kernels), **open-source MT** can generate the parallel data for the *translation* kernel without privileging any vendor:
- **Argos Translate** — fully **open-source, offline** (OpenNMT/CTranslate2), many pairs — the cleanest self-hosted option.
- **OPUS-MT / Marian** (Helsinki-NLP) — free pretrained models, hundreds of pairs.
- **NLLB** (Meta, 200 languages) — open weights (CC-BY-**NC** — non-commercial caveat; fine for research).
These feed the **dictionary + alignment** of the translation kernel; the **structure/base** work stays on **originals** (F472).

## 4. The hypothesis: definitions of words are A-N cascades (worth testing)
A dictionary **definition** is not atomic — it is a **cascade** over simpler concepts, in the classic **genus-differentia** form: *"a triangle **is a** polygon **with three** sides."* Decompose:
- **genus** ("is a polygon") = **Class E** (catalog / IS-A / parent lookup);
- **differentiae** ("with three sides", "closed", "straight") = the **A-N operations** that specialize it — **I** (cyclic count: three), **K** (compare / bound), **C** (relation / orientation), **M** (composite bind), **J** (prime/factor where numeric)…;
- **recursion**: each word in the definition is itself defined → an A-N cascade over *its* genus-differentia, **bottoming out at substrate-native concept-atoms** (words whose definitions are A-N-irreducible — the lexical primitives, cf. Wierzbicka's NSM "semantic primes" as a candidate floor, hands-to-the-linguist).
So the **dictionary kernel (F477) grounds recursively in the A-N substrate**: a definition = `E(genus) ∘ {A-N differentiae}`, and the recursion terminates at the substrate atoms. **Testable:** parse WordNet/Wiktionary definitions (the genus is extractable — WordNet hypernyms ARE the Class-E IS-A links) into operator-signatures (F463); measure how cleanly definitions factor as `E ∘ (A-N differentiae)`, and whether the recursion bottoms out at a small primitive set.
