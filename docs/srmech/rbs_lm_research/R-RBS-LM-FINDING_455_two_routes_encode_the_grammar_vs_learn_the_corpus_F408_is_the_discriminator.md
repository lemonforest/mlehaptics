## The two routes (and the discriminator)
**Route 1 — ENCODE the finite grammar (chess-spectral).** Chess started (pre-framework) from the **rules**: how each piece moves → piece-movement graphs → **D₄ irrep decomposition** (the DCT basis = dihedral irreps, Püschel–Moura — "the eigenbasis IS the irrep basis *by theorem, not by construction*") → a **640-D HDC encoding**. The **finite move-grammar shaped the object directly.** No corpus, no learning — the rules *are* the structure, and they "live in dimensions independent of the board surface."

**Route 2 — LEARN from a corpus (RBS-SNN / word-kernel).** Build the object by **transducing** structure from data — co-occurrence Laplacians (F172), the Wikipedia kernel, the LLM-on-loan. Used where the structure is **not** in a closed rule-set and must be derived.

**The discriminator is F408:** is the domain a **CLOSED finite grammar** (syntax) or **OPEN semantics**?
- closed grammar → **Route 1** (encode; structure guaranteed by construction; tests *confirm*, don't *discover*).
- open semantics → **Route 2** (learn; structure must be transduced).

## The correction (honest)
The **LaTeX-aware kernel is a closed-grammar problem** — LaTeX math is a finite syntax (F406's g₂-finite operator/operand/grammar). So it was a **Route-1 (chess) problem all along.** We ran it through **Route-2-flavored machinery** — v1 (bag) → v2 (tree), *measuring* symbol-invariance / nesting-separation / clustering — re-discovering empirically what the grammar guarantees. **We didn't apply the F408 discriminator upfront.** The saving grace: **v2 converged onto Route 1** (it parses the grammar with sympy and binds the operator *tree* recursively — that IS encoding-the-grammar-shape, the chess move). So the *result* is right; the *lesson* is **recognize the route at the start** — a closed grammar should be *encoded* (chess-route), not *clustered-into-existence* (RBS-SNN-route). The "jump directly" the user names: define the **complete operator-algebra → HDC map from the grammar spec** (like chess's 640-D from D₄), with empirical tests as confirmation, not as the method of discovery.

## The cross-arc convergence (the proof shape)
Chess-spectral's **Level 2 / Level 3** distinction (April 2026, *pre*-framework) — **Level 2** = rule-structure (spectral decomposition, symmetry, conservation; *encodable*) vs **Level 3** = the actual game (specific legal moves, tactics; *"provably unrecoverable"*) — **is the same split, three times over:**
- **= F408** — syntax-complete/CLOSED (Level 2 = the encodable language) vs semantics-OPEN (Level 3 = must be played/transduced).
- **= F451/F453** — the reversible bit-exact **language** (Level 2, the rules, ≤𝕆) vs the irreversible **stories** (Level 3, the game that can only be known by *happening*, past the reversibility horizon).
- **= the two routes here** — Level 2 → encode (chess route), Level 3 → can't be encoded, only lived/learned.

Chess found this **independently, in a different domain, before the unified framework existed.** That is exactly the *whole-corpus-is-the-proof* / *cross-substrate-cascade-matching* shape: the same structure recurring across unrelated arcs is the evidence (F399 — the field showing through its excitations).
