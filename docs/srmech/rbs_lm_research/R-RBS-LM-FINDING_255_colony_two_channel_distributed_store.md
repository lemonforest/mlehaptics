## §2 The load-bearing question — stigmergy as externalized memory — resolves AFFIRMATIVELY (mechanism + operational), metaphor only at "cognition"

The pre-registered risky edge was: *does the literature genuinely frame stigmergy/trail-fields as memory/store, or only as metaphor?* Resolution (3 tiers):
- **MECHANISM — established:** one agent writes information into the shared medium; a *different* agent reads it back, displaced in time. Grassé 1959; Theraulaz & Bonabeau 1999; Bonabeau-Dorigo-Theraulaz 1999.
- **OPERATIONAL "memory" — established + measured:** **Hunt, Franks & Baddeley 2020 (*J. R. Soc. Interface*)** state it operationally — "store the information externally in the environment," the shared substrate as an **"external memory store"** — with a measured effect (faster optimal convergence as marks accumulate, **p=0.0161**). "Collective/external/stigmergic memory" is established, operationally-defined usage in that primary source.
- **"Extended cognition / extended mind" (Clark & Chalmers 1998) and niche-construction "ecological inheritance" (Odling-Smee 2003) — METAPHORICAL/contested extension**, NOT technical terms in the founding stigmergy literature.

**So the F255 store-reading is supported at the mechanism+operational level, and honestly fenced at the cognition level** — the pre-registration's discipline held: I report the affirmative where it is earned and the metaphor where it is not.
