## Reading — a working tool, a vindication, and a self-caught circularity

1. **Door 2 (coref-as-cascade) is built and runs.** Recency (Class-I salience) × grammatical gender (Class-C) → a Centering-style resolver that pronoun-resolves at 100% against a corpus-voted gender lexicon. The cascade shape works.
2. **It vindicates F1197 in DIRECTION (5/5).** Once the noun→pronoun step is included, the referring-form contraction is unmistakable — pronouns sit ~10 tokens from their antecedent, full nouns ~1000 — the accessibility attractor (Ariel), which the framework reads as the responsion (F1186). F1197 concluded its faint 1% null was the *missing pronoun step, an instrument limitation*; F1199 adds the instrument and the effect is loud. That specific prediction of F1197 is confirmed.
3. **BUT the MAGNITUDE is circular — self-caught.** The resolver assigns each pronoun to the *nearest same-gender entity*, so pronoun antecedent-distances are small *by construction*. A recency-based resolver cannot be used to *prove* a recency-based accessibility effect without begging the question. So the ~100× is inflated; only the *direction* is trustworthy (and the direction is independently a well-attested universal).
4. **And the finer responsion CELL still isn't reachable.** Recency+gender coref is too *permissive* — it always finds *some* recent same-gender antecedent (hence 100% resolution) — so it cannot discriminate a strong/anaphoric definite (real antecedent) from a weak/uniqueness or accommodation one (F1198's split). That discrimination needs **entity-precise coreference** (which *specific* referent, via semantic identity), a harder tool than recency+gender.
