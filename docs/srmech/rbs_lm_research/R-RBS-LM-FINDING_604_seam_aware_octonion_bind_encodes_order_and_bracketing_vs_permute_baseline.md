## Verdict
**The seam-aware octonion bind encodes both order and bracketing natively** (6/6, including the same-order/different-bracket pair S1 vs S3 — the grouping the permute baseline cannot encode). The standard XOR-bind is a bag (0/6); adding permute recovers order but **structurally cannot encode bracketing** (S1≈S3=1.0) and costs an explicit permute op.

**The cost is local (F600):** grouping-sensitivity appears only across the handedness seam (within-unit defect 0, associative); order (non-commutativity) is active even within a unit. A binding-order-aware composer **routes order/parse-sensitive structure across the seam and bags order-free factors within a unit** — structure where you need it, free bag where you don't.

**Practical RBS-LM reading:** subject/verb/object order *and* nested-clause bracketing can be carried by the bind *itself* across the seam, instead of a separate permute + an external parse encoding — the concrete payoff of carrying both handednesses (F597). **Honest (F573 discipline):** symmetric tokens degenerately collapse some structures (3/6, a token artifact); generic seam-straddling tokens distinguish all 6/6 — the operator distinguishes generically.
