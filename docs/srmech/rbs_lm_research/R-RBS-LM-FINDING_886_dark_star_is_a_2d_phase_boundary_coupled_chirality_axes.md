## The bug + the fix
- `klein4_chunk_bundle(v, capacity)` makes `ceil(len/capacity)` chunks of ≤capacity each; **`capacity=1` ⇒ `len(v)` size-1 chunks**, so `[0]` is the **first bind**. F885 (and the first F886 run) used `[0]` as "M" → a single bind, not a bundle — which is why two very different loads gave **byte-identical** grids (the tell that caught it).
- **Correct single over-stuffed `M` = `klein4_bundle(*binds)`** (one reduced vector). Verified via `chunk_bundle(10,1)→10 chunks` introspection.
