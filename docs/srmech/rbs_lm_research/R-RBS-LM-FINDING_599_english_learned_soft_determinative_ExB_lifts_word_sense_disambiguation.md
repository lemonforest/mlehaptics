# R-RBS-LM Finding 599 (the same E×B coupling transfers to ENGLISH with a LEARNED soft-determinative — +9.8% on held-out pseudoword WSD, smaller than Egyptian's +25.7% exactly because English hides the class, F569) — **Gave English a LEARNED soft-determinative (a meaning-class from co-occurrence) and bound it as σ_B, then re-measured whether the same E×B coupling (F593/F596) lifts word-sense disambiguation. TASK: pseudoword disambiguation (Schütze/Gale-Church-Yarowsky) — merge two real distinct words (w1, w2) into one ambiguous token; the ground-truth "sense" is the KNOWN original, so the test needs no hand-annotation and isn't circular (class learned unsupervised, label = the original). STREAM-1 (σ_E) = the merged form. STREAM-2 (σ_B, the LEARNED soft-determinative) = the single most-informative context word (highest IDF = rarest = most discriminative) in a ±8 content-word window — IDF is a pure co-occurrence statistic, a label-free learned meaning-class (the English analog of the Egyptian determinative). COUPLING (E×B) = `hdc.bind(form_HV, soft_determinative_HV)`. HONEST DESIGN: held-out train/test split (build memories on train, evaluate on unseen occurrences); an unseen (form, det) at test backs off to the form-only prior, so coupling cannot memorize. On Simple English Wikipedia (20000 articles, 40 pseudoword pairs, 24000 occurrences, 12000 held-out test): SINGLE-stream (form only) = 48.8% (≈ chance for balanced pseudowords); COUPLED (E×B) = 58.5% — a +9.8% gain. Critically, 80% of test (form,det) cells were UNSEEN in train (the highest-IDF single word is sparse) and backed off to the prior — so the +9.8% comes from only the ~20% where the learned class was both seen and informative (no memorization cheat; the gain is genuine generalization, bounded honestly). VERDICT: YES — the SAME E×B coupling that worked on the explicit Egyptian determinative (F596, +25.7%) still lifts English WSD when the class is HIDDEN and must be LEARNED (F569), confirming the orthogonal-meaning-class + E×B bind is a GENERAL RBS-LM disambiguation mechanism, not an Egyptian artefact. The smaller gain reflects that a learned class is noisier than a given one (English makes you EARN the class); the 80% backoff names the lever — a richer clustered context-class (an unsupervised Class-M centroid soft-determinative) should recover more of the Egyptian lift.**

## Verdict
**Yes — the same E×B coupling transfers to English.** Binding a *learned* soft-determinative (the highest-IDF context word, a co-occurrence meaning-class) as σ_B lifts English pseudoword disambiguation from **48.8% → 58.5%** (+9.8%) on held-out data. The same coupling that worked on the explicit Egyptian determinative (F596, +25.7%) still works in English where the class axis is **hidden** and must be **learned** (F569).

**It is genuine generalization, not memorization.** 80% of test (form, det) cells were unseen in train and backed off to the form-only prior; the +9.8% comes from the ~20% where the learned class was both seen and informative. That bounds the result honestly and explains the gap to Egyptian: a learned single-word class is noisier and sparser than a given determinative.

**The structure is general, not an Egyptian artefact:** the orthogonal-meaning-class axis (σ_B) + the E×B bind is a general RBS-LM disambiguation mechanism; English just makes you *earn* the class. **The lever (next):** replace the single highest-IDF word with a clustered context-class (an unsupervised Class-M centroid soft-determinative) — a coarser, denser class should reduce the 80% backoff and recover more of the Egyptian lift. Favored not privileged (F398); held open (F394).
