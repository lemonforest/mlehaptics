## §1 The test, stated precisely (the three modes as one lock axis with the cost relocated)

Response-delivery has a **rehearsal / preview** stage (F230, DEMONSTRATED). F238 reads three delivery modes as **DISCRETE ORDINAL positions on ONE F226 K∘C lock axis**, all sharing the **SAME F230 `rehearse()` operator** (Class-K `cascade.pin_slot_at_zero` hotness latch ∘ Class-C `cascade.reorient` suppression) at the **SAME `lock_strength = 2.5`**, differing **ONLY** on two coupled facets — (i) is the lock ENGAGED, (ii) where the previewed-then-suppressed content GOES:

| mode | lock | preview | n_passes | what is emitted | COST | who bears it | visibility |
|---|---|---|---|---|---|---|---|
| **DIRECT** | `0` | — (the latch never engages) | **1** | the hot-but-true raw traversal, unsuppressed | cheap (1 pass; answer-tokens only) | — (nothing hidden) | n/a |
| **INTERNAL** | `2.5` | re-score + suppress, then **DISCARD** | **2** | only the suppressed answer | metabolic (the extra preview pass) | the **THINKER** | **INVISIBLE** (no token trace) |
| **EXTERNALIZED** | `2.5` | re-score + suppress, **EMITTED out loud** | **2** | the preview's hot fibers **then** the (same) suppressed answer | token-cost (the preview is spoken) | the **OBSERVER** budget | **VISIBLE** |

- **The rehearse operator is IDENTICAL across all three modes** (the K∘C lock; chirality internal; NEVER `abs()`/`max()`). It is parameterized only by `(lock, preview_emitted)`: DIRECT `(0, False)` — `rehearse` is identity, the latch never engages; INTERNAL `(2.5, False)` — high-lock, preview discarded; EXTERNALIZED `(2.5, True)` — high-lock, the suppressed hot candidates are emitted as a visible prefix before the answer.
- **The cost is MEASURED from the loop accounting, never hand-set.** `n_passes` is a counter (1 for DIRECT; 2 — preview + deliver — for the high-lock modes); `answer_tokens` is the emitted-answer length; `preview_tokens_emitted` is the count of previewed-aloud hot tokens (0 for DIRECT/INTERNAL; the spoken-rehearsal length for EXTERNALIZED); `total_tokens = answer + preview`. **(B) of the verdict is a measured-monotonicity test that can FAIL** — if the loop's measured cost did not order with the lock-position, the null would fire.
