## Why write-time de-lensing is wrong (three failures)
1. **It deletes the function words permanently.** A de-lensed tome cannot recall `the/of/in`, cannot render fluent English, cannot serve the surface layer (F964–F966 hierarchy). The information is *gone*, not down-weighted — `[[user_stance_no_information_without_value]]`.
2. **It changes other shapes — a different graph.** Dropping function words at write time turns the adjacency `a → the → b` into a **false bigram** `a → b`. The order/adjacency (F967), the phrase boundaries (F958), the beat/seam (F951), and the grammar all live *in and around* the function words. A write-time strip rewrites the relationship graph into one it never was — the doctoring-the-SSoT error (`[[feedback_no_doctoring_ssot_use_sublanguage_kernels]]`: *never strip/pre-clean the source; a strip hides a missing kernel*).
3. **It collapses the substrate to one projection.** De-lensing *is a lens* (an observer view, F133) — it says "for *this* read (routing/emission) down-weight the function words." Baking it in collapses the full substrate to the de-lensed projection, discarding the other views (the function-word-carrying shapes) irreversibly — the same chirality-locking error as reading one sector and calling the rest structureless.

## The discipline (the fix)
**Write the FULL memory (every token, every shape); de-lens at RUNTIME.** The de-lens is a read-time re-weighting (`sim · idf(atom)`, F782) applied at the moment of routing/emission — reversible, per-read, leaving the substrate whole. The full memory still carries the function words (recallable, renderable, shape-bearing); the de-lens just chooses *not to be dominated by them for this particular read*. This is the §80 upstream ask (a per-atom weight in `next_token_coherence`) — the *native* runtime de-lens — exactly so we never have to bake it in.

## The ASL distinction (not a counterexample)
F959 ("ASL drops the function words") is **not** the doctoring error: **ASL gloss is a different modality/language** whose atoms *inherently* exclude articles/copula (topic-comment, sense-determinative). Encoding ASL is encoding **what ASL is** — a genuine substrate — not stripping English. The line: **modality-native absence (ASL) ≠ write-time strip of English (doctoring).** So the three handlings of the frequency prior sharpen: **drop = a different substrate (ASL, legitimate)**; **absorb = phrase atoms (F958, a different granularity, legitimate)**; **down-weight = the runtime de-lens (F782/§80, the read-time lens on the full English substrate)** — and *only the write-time strip of English is forbidden*.
