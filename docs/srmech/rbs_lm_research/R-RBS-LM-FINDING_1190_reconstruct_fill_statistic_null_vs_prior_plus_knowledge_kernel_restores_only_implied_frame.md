## Result 1 — the fill statistic is a NULL vs the prior at equal budget

Averaging over ~40 held-out offering lines (mask a random half, recover it), with every mode ranked and **capped to the same guess budget** `|masked|` (so no mode wins by guessing MORE):

| mode | equal-budget recall |
|---|---|
| PRIOR (guess commonest offering lemmas, context-free) | **0.505** |
| FAMILY (siona.reconstruct local spectral consensus) | **0.505** |
| FAMILY + KNOWLEDGE | **0.505** |

**All three identical.** The F1189 4/13≈0.31 was one operand-heavy line; averaged, the fill sits at ~0.50 = the frame-fraction of a line. And the family does NOT beat the prior here — because the offering formula is **maximally canonical**, so the local spectral family is just a sample of the same canonical frame the global frequency already ranks first. The earlier uncapped "family 0.610 vs prior 0.527" was partly a guess-**volume** artifact (family proposes more words); the fair equal-budget comparison removes it and the advantage vanishes. This is the F1176 reading confirmed from the null side: **the family's value is GROUPING (98% capture, F1189), not FILLING** — filling degenerates to "guess the frame" on a text this formulaic (the corpus-side of the Three-Kingdoms/Journey regime split, F1174). The fill **ceiling** is the frame-fraction (~50%); every method reaches it; the residual ~50% is the unique operand no in-corpus method touches (F1175).

## Result 2 — the knowledge kernel restores ONLY the implied frame (17 frame / 0 operand)

The offering formula is **elliptical by convention**: a line abbreviates the canonical frame because it was implied (everyone knew *pr.t-ḫrw tʾ ḥnq.t kꜣ ꜣpd šs mnḫ.t* = "invocation-offerings of bread, beer, ox, fowl, alabaster, linen"). A corpus-attested **genre-template kernel** (frame = lemmas in ≥6% of offering lines; fired only when the surviving context carries the offering **trigger** — "because of something implied"):

- uncapped recall **0.547 → 0.606** (+6pp), precision **0.463 → 0.429** (−3.4pp) — it trades precision for recall by proposing the canonical frame;
- lift decomposition: **17 frame-lemmas, 0 operand-lemmas.** The kernel restores EXACTLY the elided-because-canonical frame and touches ZERO of the unique operand.

This is `op(x)operand(x)EC` made operational as **two complementary, MEASURED-DISJOINT EC sources**: the genre-template kernel corrects the OP-frame the ellipsis deliberately omitted (implied ↔ frame ↔ knowledge-recoverable); the corpus-parallel / Rosetta / expert corrects the unique operand (specified ↔ operand ↔ external-only, F1188/F282). The knowledge kernel does **not raise the fill ceiling** (equal-budget still 0.505) and knowledge-alone is a poor fill strategy (fires only when the trigger survives); its value is **targeted, provenance-labeled implied-frame recall** — which for a reconstruction *proposal* tool is the right trade: an epigrapher can cheaply accept/reject a "canonical-frame candidate" but cannot invent the name. So `reconstruct` returns the genre proposals **separately** as `implied`, never merged into the corpus `recovered`. The genre template is **responsion at the genre scale** (F1179/F1186): the canonical pattern every instance answers to; the elided line is a strophe, the template its responsion-form.
