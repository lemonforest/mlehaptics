## Reading — a faint real whisper, blocked by a tooling boundary

The contraction is there in **direction** — every novel's first mention is longer than its later mentions, and 6/6 same-sign is itself significant (p≈0.016). But the **magnitude** is tiny and mostly within each novel's order-shuffle null, for two structural reasons the trajectories make obvious (e.g. entities caught are `man / little / great / sister` — general lemmas, not single referents):

1. **Floor-dominated.** Mean NP length is ~2 at *every* mention index. English prose introduces entities short ("a house"), not with long modifier stacks ("a large old house"), so the length floor is reached at the first mention and there is almost no length to shed. The rich modifier-shedding the probe was built to catch is rare.
2. **Coreference-blind.** Anchoring on head-noun *lemmas* conflates distinct referents — the "5th mention of *man*" is a different man, so the per-lemma mention index is NOT a per-referent accessibility index, which dilutes the decay. And the *biggest* contraction step — noun → **pronoun** ("the house" → "it") — is invisible, because when the entity contracts to "it" it leaves the noun count entirely. Both require **coreference resolution** to measure, which the numpy-free / parser-free sparse toolkit does not provide.

So this is not evidence the responsion is absent; it is evidence that **confirming it requires coreference tooling** the framework's sparse discipline deliberately excludes. The attractor-contraction IS the well-attested referential-form / accessibility decay (Givón topic-continuity; Ariel's accessibility scale) — the framework reads that phenomenon *as* the responsion — but reading it and *measuring it cleanly from raw text* are different, and the clean measurement is coref-gated.
