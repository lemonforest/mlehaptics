## The reading (what the null teaches, and what already works)
- **The low modes are community coordinates; their big rows are community ANCHORS.** `loa` (law), `man`, `pikinini` (child) are the topical hubs of the UDHR's article-communities — exactly what Fiedler-band eigenvectors encode. Operator words *bridge* communities, so they are not the extremes of any community coordinate; and the normalized Laplacian moves pure hub-ness into the *trivial* mode (∝ √deg), which the band excludes. The naive "operators = low-band" mapping conflates two different kinds of low-frequency structure.
- **Reported straight: three declared features, three chance-level transfers, one inverted direction.** Per the no-pre-commit discipline these were declared with predicted directions before running; the IPR inversion (function words MORE localized on English) is itself informative — likely the D^{-1/2} row-scaling — and is left as measured, not tuned away.
- **The honest positive reframe: the RULE the user wants already transfers.** F984's doc-freq gate is a *pre-learned language rule* in exactly the sense asked for: "operator-class = high document-frequency" is language-agnostic, needs NO labels and NO word-learning — only the new corpus's own statistics (it built the Bislama strip set in F1016 automatically). What the spectral shape was hoped to add — role sub-structure (interrogative vs copula vs conjunction) — is the genuinely open part, and it plausibly lives in the **directed** signature: interrogatives are sentence-initial, copulas medial — position asymmetry = directed edges = **magnetic-Laplacian flux** (F1007), untested here and the sharpest scoped next probe.
- **The ASL insight (user) composes with F608/F609 and F1018 rather than needing new theory:** ASL lexicalizes MEANING — F608 read the sign as a chord with **sense as the determinative**, and F609 *measured* that a meaning-class-explicit source selects ASL signs better than written English. So for a polysemous written word, the ASL gloss set is an **attested sense-split**: one spelling → distinct glosses = the natural **labels for the F1018 superposition rungs** (`save@RESCUE-class` vs `save@STORE-class` as rung identities grounded in a human language that already did the splitting). The local R-RBS-LM-27 corpus is a mini smoke set (`save`/`remember` absent) — whether ASL splits `remember` specifically is a question for the **attested source (ASL-LEX / the gloss corpus), never training data**; gate item added with that requirement.
