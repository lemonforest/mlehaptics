## The reading (the complementary split, wired and validated)
- **Propose→resolve beats both alone (+7pp).** Neither representation is best overall: the sparse bundle has the coverage (F998c: 92% top-5) but a soft top-1 (47%); the resonant kernel has the sharpness but a noisier tail over the whole tome (53%). Composing them — **propose with the sparse bundle, resolve with the resonant kernel restricted to the proposed set** — uses each for its strength and beats either: 60% (propose-3) > 53% > 47%. This grounds F998's translation-bridge *as* a propose→resolve pipeline and F978's "propose a distribution, sharpen when confident."
- **A tighter propose set is the sweet spot (propose-3 60% > propose-5 57%).** The resonant re-rank is *most precise on a small, high-coverage candidate set* — top-3 trades a little coverage for a much sharper resolve. So the pipeline has a tunable knob (propose width K) with an interior optimum, not "wider is better."
- **Density stays in the bounded bridge, applied to ~3 candidates.** The resonant resolve runs only on the proposed top-K (≤5), not the whole tome — so the bounded kernel (F998b) is applied to a tiny set where it is strongest, and storage stays the sparse edges (F998). The architecture is honored exactly.
