## Reading — the determinative gate is a real, non-circular precision gain

1. **The class-gated coref is built and it works.** F1199's recency resolver + the F1201 class-lexicon as the gate. The class gate corrects a **majority (57%)** of the cross-class antecedent errors pure recency makes: in narrative, person and thing mentions interleave densely, so the *nearest* noun to a "he" is usually a thing/place ("the room", "the table"), and pure recency would wrongly resolve there — the determinative gate skips to the nearest *person*. That is exactly the entity-precise resolution F1197/F1198/F1199 could not reach.
2. **It is NON-CIRCULAR** — the property F1199 lacked. F1199's gender-coref was circular (nearest-gender-match forced small distances). Here the class is **precomputed in the lexicon, independent of the coref's recency**, so the gate genuinely constrains resolution without begging the question. The 2.3× candidate reduction is the F1200 structural claim (referents/classes) measured in practice.
3. **Honest ceiling — the lexicon's accuracy.** The English class-lexicon is WEAK (F1201: 32% cross-cue agreement, ~sensible in aggregate but noisy), so 57% is an *upper-ish* bound: some "corrections" resolve to a mis-classed entity, and the true correct-correction rate is bounded by the lexicon's quality. The gate is real; its ceiling is the determinative dictionary. A cleaner lexicon (ConceptNet IsA + a class seed-set + the corpus cues, layered) would raise the ceiling; a finer gate than 2-class animacy (the full person/place/thing/abstract, or the Sumerian ~16) would correct more. **Where the class is WRITTEN (Sumerian/Egyptian determinatives, German gender-vestige) the gate is strong and clean; where it is DISTRIBUTED+weak (English) the gate is real but capped by recovery quality** — the relational-vs-distributional axis, again.

## The arc, synthesized (F1192 → F1202)
The responsion / "hidden content" the whole grammar thread chased = the referent's **class**. Alphabetic writing omits it (English) or vestigially marks it (German gender, 3-class) or writes it fully (Sumerian determinatives, ~16-class). So: (a) the responsion is coref-gated (F1197–F1199); (b) the coref is a **class-gate** problem, and the class gate is the **determinative** (F1200); (c) English *distributes* the determinative weakly across the grammar, recoverable only as an aggregate lexicon (F1201, #2 conditionally feasible); (d) the **class-gated coref** (F1202, #1) built on that lexicon gives a large non-circular precision gain (57% cross-class correction). **One learned determinative dictionary serves BOTH directions**: Siona *gates coref* with it when READING (#1), and *writes it as an explicit class-tag* when GENERATING (#2, the render-side fix) — write the determinative, as Gilgameš's scribes did.
