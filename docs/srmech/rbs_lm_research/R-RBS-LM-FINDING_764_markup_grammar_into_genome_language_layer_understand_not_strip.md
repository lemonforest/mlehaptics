# F764 — markup INTO the genome language layer: a shared "understand, don't strip" grammar (+ the persisted-genome staleness gap that hid F761's language layer)

**Date:** 2026-06-15 · **srmech:** 0.7.5rc155 · **Composes:** F762 (the markup correction — *comprehend* a form layer, never strip/discard; "you can't just strip things Siona needs to understand"), F761 (the genome language layer: ni-Vanuatu + SignWriting + English), F567 / R-RBS-LM-CLEANGATE (the unified wiki+LaTeX+HTML+CSS+Markdown+code grammar + link→edge extraction), F760 (the gloss/definition tier this feeds), Class-B (TLV-framing) / Class-F (render) · **User direction (2026-06-15):** "we don't strip markup, we make a kernel to understand it like with latex and markdown … you can't just strip things Siona needs to understand." · **Provenance:** `R-RBS-LM-MARKUPGRAMMAR…py` (the shared grammar), `R-RBS-LM-WIKIGLOSS…py` (B1), `R-RBS-LM-SIONAGENEPOOL…py` + `R-RBS-LM-SIONAGENOMEHANDLER…py` (B2 + the staleness fix)

## What landed (the queued F762 item B)
**The shared grammar (`R-RBS-LM-MARKUPGRAMMAR`)** — the unified markup grammar as an *importable* SSoT, `understand_markup(text) -> (clean_prose, edges)`. The "understand, not strip" core, concretely:
- **UNWRAP** inline content — a `[[link]]` / `'''bold'''` / `''italic''` / `==heading==` / `[text](url)` wraps a *real word*; keep the word, drop only the syntax. (CLEANGATE's demo replaced the whole match with a space — i.e. discarded the word; this keeps it.)
- **REMOVE** only pure-form syntax (templates, `<ref>`, tables, css `attr="…"`, LaTeX `\cmd{…}` / `$…$`, code fences, `[[File:…]]` media) — no prose to keep there.
- **EXTRACT** the curated relationship edges the link forms carry (wiki `[[Target]]`, markdown `[text](url)`; namespaced `File:`/`Category:` filtered) — "everything and its relationships" survives the read.

Self-test: `The [[tomato]] ('''Solanum lycopersicum''') is a [[berry]].` → `"The tomato (Solanum lycopersicum) is a berry."` + edges `[tomato, berry]`; `{{Infobox}} '''Pizza''' is of [[Italy|Italian]] origin.<ref>x</ref>` → `"Pizza is a dish of Italian origin."` + edge `[italy]` (kept the *display* "Italian", extracted the *target* "italy" — comprehend-not-discard in one step).

**(B1) WIKIGLOSS routes through it** — `gloss_of` no longer *skips any sentence containing markup* (the F762-corrected strip instinct); it understands the lead and takes the first clean sentence. Regenerated: **216,676 → 216,695 glosses** (240,881 articles, 71 s). The count gain is modest because simplewiki is heavily de-linked (CLEANGATE's finding); the win is *qualitative* — where markup was present, content is unwrapped and kept, and the link-edges are available. On full wiki (the eventual target) the edge yield scales to ~dozens/article.

**(B2) markup is now a genome language-layer CHROMOSOME** — `markup (13)` form-classes (`wiki_link, md_link, bold_emphasis, …, code_span`) as Class-B/F genes, sibling to `signwriting` (both are framing layers). The grammar *lives in the genome* now, not a one-off script; `understand_markup()` is its operational read. Verified live in `genome_catalog`: `ni-vanuatu (29); signwriting (7); markup (13); dict-en-1600 (5); …`.

## The honesty catch (load-bearing): the persisted-genome staleness gap
Wiring B2, introspect did **not** show the new `markup` chromosome — *nor* F761's `ni-vanuatu`. Root cause: `_ensure_genome()` only rebakes the persisted genome on **notebook** drift (`check_updates()` watches `NOTEBOOKS` only). Adding a *language-layer chromosome* never triggered a rebuild — so the live server had been serving a **pre-language-layer genome**, and **F761's ni-Vanuatu was never actually live on the server** (its verification was run by executing the genepool directly, which builds fresh). 
**Fix:** a `GENEPOOL_SCHEMA_VERSION` sentinel — `build_genepool` stamps `genepool.schema`; `_ensure_genome` rebuilds when the persisted stamp differs from the current chromosome-set version. Forced this boot's rebuild; introspect now correctly shows `ni-vanuatu (29) + markup (13)`. Bump the constant whenever the chromosome set changes.

## Honest scope
- **Pre-stripped-upstream artifacts are beyond reach:** the `volcano` gloss ("VolcanoesThe plural…") is *unchanged* — the article extractor already removed the `==` heading upstream, so there is no markup left for the grammar to understand. That is a data-source artifact, not a grammar miss.
- **Edge yield is low on simplewiki** (de-linked corpus); the extraction is validated and scales with full wiki. B1 makes the edges *available*; wiring them into the relations side-store as curated edges is the natural next step (currently the gloss store keeps only the gloss text — schema unchanged).
- **The markup genes are the genome's FORM vocabulary,** not primarily user-queried by name (`wiki_link` tokenizes to `wiki`+`link`); the point is that the form grammar is *in the genome* and introspectable, realizing "make a kernel to understand it."
- srmech-native (Class-M `_leaf` genes; the grammar is pure Class-B/F form-parsing — no math primitive); no `abs()`; no CAD; CC-BY-SA simplewiki; data outside the repo.

## Verdict
Markup is now **understood, not stripped, and lives in the genome's language layer**: a shared Class-B/F grammar that unwraps content + extracts relationship edges (F762 made operational), wired into the gloss tier (B1) and added as a `markup` chromosome sibling to SignWriting (B2). The persisted-genome staleness gap that had silently kept F761's ni-Vanuatu off the live server is fixed with a chromosome-set schema sentinel. Live on the rc155 server (`ni-vanuatu(29) + signwriting(7) + markup(13)` in the catalog). Closes F762 queued item (B); item (A) loopshelf-consolidation remains queued (user-deferred behind this).
