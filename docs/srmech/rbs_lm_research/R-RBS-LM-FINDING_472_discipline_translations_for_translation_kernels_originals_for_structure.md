# R-RBS-LM Finding 472 (methodology discipline — STANDING) — **use translated texts ONLY for translation kernels; use ORIGINAL texts for structure.** A translation **re-grammars** the source into the target language (imposing the target's word order, morphology, function words, and the translator's style), which **overwrites exactly the source-language structure** that the deviation-from-substrate lens (F467/F469/F471) measures. So a translation can never be evidence about its source language's *structure* — only about the *target* language's register and about the *translation relation* itself. This cleanly partitions corpus usage: **translated texts → translation kernels** (the Rosetta / cross-language meaning work, R-RBS-LM-53/54, where translation *is* the object of study); **original texts → structure** (the deviation-from-substrate program and the ancient-language A-test). F471's register proxy is the proof: the English Quran/KJV/Gita/Tao order-asymmetries measured the *English translations*, not the source tongues — correctly flagged there as confounded, and now reclassified to the translation domain by this rule.

## The rule, and why it is load-bearing
| use | corpus | because |
|---|---|---|
| **translation kernel** (R-RBS-LM-53/54; the Rosetta layer, F458 anchor) | **translated** texts (and bilinguals) | the object IS the cross-language meaning map; translations are the data |
| **structure** (deviation-from-substrate, F467/F469/F471; the ancient-language A-test) | **original** texts (original script / faithful transliteration) | structure = the source grammar + order; translation OVERWRITES it with the target's |

**Why translation destroys the structural signal precisely:** the deviation lens reads (a) the co-occurrence bag (K1, vocabulary) and (b) the directed order (K3, the magnetic-Laplacian gap, F471). A translation **rewrites the word order and function-word skeleton into the target language** — so the K3/order channel (the one that carries generation, F471) measures the *translator's* English, not the source. Even the K1 bag is the translator's lexical choices. There is *no* channel of a translation that reports the source structure. Hence: **structure ⇒ originals, full stop.**

## Falsifiable / scope
- **Falsifiable corollary:** a translation's structural signature should track the *target* language, not the source — e.g., the *same* source text in two different target languages should diverge structurally (toward each target), while two *different* source texts translated into the *same* target should converge (toward that target). That is the test that would confirm "translation = target structure" (a clean R-RBS-LM-53f-style follow-up, translations appropriate there).
